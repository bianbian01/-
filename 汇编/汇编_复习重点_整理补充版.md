
# 第一章：汇编语言基础

## 1.1 本章复习定位

第一章重点不是写程序，而是建立 IA-32 汇编程序运行的硬件模型：

- IA-32 常用寄存器名称和作用；
- EFLAGS 中常用状态标志；
- 段寄存器、EIP 和逻辑地址；
- 存储模型与工作方式；
- 实地址方式下物理地址计算；
- 源程序基本结构。

考试常见题型：填空题、判断题、选择题、简单地址计算题。

## 1.2 处理器与计算机系统

### 1.2.1 基本概念

- 处理器 Processor / CPU：计算机的运算和控制核心。
- 微处理器 Microprocessor：通常指单片 CPU 芯片。
- 微型计算机 Microcomputer：微处理器 + 主存储器 + I/O 接口等硬件。
- 微型计算机系统 Microcomputer System：微型计算机 + 外设 + 软件。

### 1.2.2 冯·诺依曼计算机结构

冯·诺依曼结构的核心特点：

1. 存储程序；
2. 程序控制；
3. 程序和数据都以二进制形式存放在存储器中。

五大部件：

- 运算器；
- 控制器；
- 存储器；
- 输入设备；
- 输出设备。

三个硬件子系统：

- 处理器；
- 存储系统；
- 输入输出系统。

汇编语言程序员通常把硬件抽象成：

- 寄存器；
- 存储器地址；
- 输入输出地址。

## 1.3 IA-32 常用寄存器

IA-32 中应用程序最常见的可编程寄存器包括：

- 8 个 32 位通用寄存器；
- 6 个 16 位段寄存器；
- 32 位 EFLAGS 标志寄存器；
- 32 位 EIP 指令指针寄存器。

## 1.4 通用寄存器

IA-32 有 8 个 32 位通用寄存器：

| 32位寄存器 | 16位形式 | 8位形式 | 常见含义 | 典型用途 |
|---|---|---|---|---|
| EAX | AX | AH / AL | Accumulator 累加器 | 算术逻辑运算、函数返回值、乘除法隐含寄存器 |
| EBX | BX | BH / BL | Base 基址寄存器 | 保存变量或数组基地址 |
| ECX | CX | CH / CL | Counter 计数器 | LOOP、REP 等循环/重复指令的隐含计数器 |
| EDX | DX | DH / DL | Data 数据寄存器 | 乘除法高位、余数、端口地址 |
| ESI | SI | 无 | Source Index 源变址寄存器 | 指向源字符串或源数组 |
| EDI | DI | 无 | Destination Index 目的变址寄存器 | 指向目的字符串或目的数组 |
| EBP | BP | 无 | Base Pointer 基址指针 | 子程序中访问堆栈参数和局部变量 |
| ESP | SP | 无 | Stack Pointer 堆栈指针 | 指向当前栈顶 |

### 高频填空题

IA-32 处理器有 8 个 32 位通用寄存器，其中 `EAX、EBX、ECX、EDX` 可以分成 16 位和 8 位操作，另外 4 个是 `ESI、EDI、EBP、ESP`。

### 易错点

只有 `EAX、EBX、ECX、EDX` 可以拆成 8 位寄存器：

```asm
EAX -> AX -> AH / AL
EBX -> BX -> BH / BL
ECX -> CX -> CH / CL
EDX -> DX -> DH / DL
```

`ESI、EDI、EBP、ESP` 只能使用其低 16 位形式 `SI、DI、BP、SP`，不能写成 `SIL、DIL` 这类 32 位模式下课程未涉及的形式。

## 1.5 专用寄存器

### 1.5.1 EIP 指令指针寄存器

EIP 保存下一条将要执行的指令在当前代码段中的偏移地址。

- 顺序执行时，处理器自动让 EIP 增加，指向下一条指令；
- 分支、循环、调用、返回等控制转移指令会改变 EIP；
- 完整取指地址通常表示为 `CS:EIP`；
- 16 位实地址方式下只使用低 16 位 `IP`。

### 1.5.2 EFLAGS 标志寄存器

EFLAGS 保存指令执行结果的辅助信息和控制信息。考试重点主要是状态标志。

## 1.6 常用状态标志

常用状态标志可记为：`Z C O P S`，另有 AF。

| 标志 | 中文名 | 置 1 条件 | 主要用途 |
|---|---|---|---|
| CF | Carry Flag 进位标志 | 无符号加法有进位，减法有借位 | 判断无符号运算是否越界 |
| PF | Parity Flag 奇偶标志 | 结果最低字节中 1 的个数为偶数或 0 | 奇偶校验 |
| AF | Adjust Flag 辅助进位标志 | 低半字节有进位/借位 | BCD 运算，通常不是重点 |
| ZF | Zero Flag 零标志 | 运算结果为 0 | 判断相等或为 0 |
| SF | Sign Flag 符号标志 | 结果最高位为 1 | 判断结果符号 |
| OF | Overflow Flag 溢出标志 | 有符号数运算结果超范围 | 判断有符号溢出 |

### CF 与 OF 的区别

- CF 面向无符号数：判断无符号加减是否产生进位/借位。
- OF 面向有符号数：判断有符号加减结果是否超出可表示范围。
- 同一条 ADD/SUB 指令会同时设置 CF 和 OF，但程序员根据数据含义选择关注哪个标志。

例：8 位运算 `3AH + 7CH = B6H`

- 无符号：58 + 124 = 182，未超过 255，所以 CF=0；
- 有符号：58 + 124 = 182，超过 127，结果最高位为 1，产生溢出，所以 OF=1。

## 1.7 控制标志和系统标志

课程重点一般只需掌握以下控制标志：

- DF：Direction Flag，方向标志，仅用于串操作指令。
  - DF=0：串操作后地址自动增加，从低地址向高地址处理；
  - DF=1：串操作后地址自动减少，从高地址向低地址处理；
  - `CLD`：DF=0；
  - `STD`：DF=1。

其他系统标志如 IF、TF、IOPL 等了解即可。

## 1.8 段寄存器

6 个 16 位段寄存器：

| 段寄存器 | 名称 | 作用 |
|---|---|---|
| CS | Code Segment | 当前代码段 |
| DS | Data Segment | 当前数据段 |
| SS | Stack Segment | 当前堆栈段 |
| ES | Extra Segment | 附加段，串操作常用 |
| FS | 附加数据段 | IA-32 增加的数据段性质寄存器 |
| GS | 附加数据段 | IA-32 增加的数据段性质寄存器 |

常见组合：

- `CS:EIP`：取下一条指令；
- `SS:ESP`：当前栈顶；
- `DS:有效地址`：普通数据访问默认段。

## 1.9 存储器组织与存储模型

### 1.9.1 存储器组织

存储器用于存放程序和数据。主存按字节编址，每个字节都有唯一地址。

从程序员角度看，数据可能位于：

- 寄存器；
- 主存变量；
- 堆栈；
- I/O 地址。

### 1.9.2 三种存储模型

| 存储模型 | 特点 |
|---|---|
| 平展存储模型 Flat | 段基地址通常为 0，偏移地址近似等于线性地址，是 Win32 汇编最常用模型 |
| 段式存储模型 Segmented | 逻辑地址经段机制转换为线性地址，线性地址 = 段基地址 + 偏移地址 |
| 实地址存储模型 Real-address | 兼容 8086，物理地址 = 段地址 × 16 + 偏移地址 |

## 1.10 工作方式

| 工作方式 | 特点 |
|---|---|
| 保护方式 Protected Mode | IA-32 常态工作方式，支持 4GB 物理地址空间、分段、分页、保护机制、多任务，Windows/Linux 运行于保护方式 |
| 实地址方式 Real-address Mode | 处理器复位后的初始方式，只能访问最低 1MB，段最大 64KB，地址转换为段地址左移 4 位加偏移地址 |
| 系统管理方式 System Management Mode | 用于电源管理、系统控制等，普通应用程序一般不直接使用 |

## 1.11 逻辑地址与地址转换

### 1.11.1 逻辑地址

逻辑地址一般写作：

```text
段地址/段选择器 : 偏移地址
```

在取指时：

```text
CS:EIP
```

### 1.11.2 保护方式地址转换

保护方式下：

```text
逻辑地址 -> 段转换 -> 线性地址 -> 可选分页转换 -> 物理地址
```

- 平展模型：段基地址为 0，线性地址 = 偏移地址；
- 段式模型：线性地址 = 段基地址 + 偏移地址。

### 1.11.3 实地址方式地址转换

实地址方式：

```text
物理地址 = 段地址 × 10H + 偏移地址
         = 段地址左移 4 位 + 偏移地址
```

例：`7380H:0400H`

```text
段起始地址 = 7380H × 10H = 73800H
物理地址   = 73800H + 0400H = 73C00H
```

## 1.12 源程序基本结构

本课程常见 MASM/VS 模板：


# 第二章：数据表示和寻址

## 2.1 本章复习定位

第二章重点是“数据怎么表示、变量怎么定义、操作数怎么寻址”。老师黑板重点中提到：

- 补码、进制转换、ASCII；
- 变量应用；
- 变量属性：地址属性、类型属性；
- Intel 小端方式；
- 数据寻址方式：立即数、寄存器、存储器。

考试常见题型：补码计算、十六进制加减、ASCII 填空、DUP 空间计算、变量存储图、寻址方式判断。

## 2.2 数制

### 2.2.1 二进制、十进制、十六进制

- 二进制 Binary：后缀 `B`，例如 `01100100B`；
- 十进制 Decimal：可无后缀，也可用 `D`；
- 十六进制 Hexadecimal：后缀 `H`，例如 `64H`。

注意：以 A～F 开头的十六进制常数必须加前导 0。

```asm
0B800H   ; 正确
B800H    ; 错，可能被识别为标识符
```

### 2.2.2 二进制与十六进制转换

每 4 个二进制位对应 1 个十六进制位：

```text
0011 1010B = 3AH
F2H = 1111 0010B
```

### 2.2.3 十六进制加减法

- 加法：逢 16 进 1；
- 减法：借 1 当 16。

例：

```text
  23D9H
+ 94BEH
= B897H
```

```text
  A59FH
- 62B8H
= 42E7H
```

## 2.3 数值编码：原码、反码、补码

### 2.3.1 基本概念

- 机器数：计算机中存放的二进制编码；
- 真值：现实中的数学值；
- 正数的原码、反码、补码相同；
- 负数补码：绝对值二进制按位取反再加 1。

### 2.3.2 补码范围

N 位补码表示有符号整数范围：

```text
-2^(N-1) ~ +2^(N-1)-1
```

N 位无符号整数范围：

```text
0 ~ 2^N - 1
```

常见范围：

| 位数 | 无符号范围 | 有符号补码范围 |
|---|---|---|
| 8位 | 0 ~ 255 | -128 ~ +127 |
| 16位 | 0 ~ 65535 | -32768 ~ +32767 |
| 32位 | 0 ~ 2^32-1 | -2^31 ~ 2^31-1 |

### 2.3.3 负数补码例题

8 位表示 `-32`：

```text
+32 = 0010 0000B = 20H
取反 = 1101 1111B
加 1 = 1110 0000B = E0H
```

所以：

```text
[-32]补码 = E0H
```

32 位表示 `-38H`：

```text
+38H = 00000038H
取反 = FFFFFFC7H
加 1 = FFFFFFC8H
```

所以：

```text
[-38H]补码 = FFFFFFC8H
```

### 2.3.4 补码运算

```text
[X]补码 + [Y]补码 = [X+Y]补码
[X]补码 - [Y]补码 = [X]补码 + [-Y]补码
```

## 2.4 字符编码

### 2.4.1 BCD

BCD：用 4 位二进制表示 1 位十进制数字。

- 压缩 BCD：一个字节表示两位十进制数；
- 非压缩 BCD：一个字节表示一位十进制数，低 4 位有效。

### 2.4.2 ASCII

常见 ASCII 必背：

| 字符 | ASCII |
|---|---|
| 空格 | 20H |
| '0' ~ '9' | 30H ~ 39H |
| 'A' ~ 'Z' | 41H ~ 5AH |
| 'a' ~ 'z' | 61H ~ 7AH |
| 回车 CR | 0DH |
| 换行 LF | 0AH |

大小写字母差值：

```text
'a' - 'A' = 20H
```

大写转小写：

```asm
or al, 20h
; 或 add al, 20h
```

小写转大写：

```asm
and al, 5fh
; 或 sub al, 20h
```

## 2.5 常量表达

### 2.5.1 常数

```asm
255
100d
64h
01100100b
```

### 2.5.2 字符与字符串常量

```asm
'A'
'Hello'
"Hello"
```

字符和字符串在内存中存放的是 ASCII 码。

### 2.5.3 符号常量

```asm
minint equ 10
maxint = 0ffh
msg equ <Hello>
```

特点：

- 符号常量不分配内存；
- 汇编时用对应值替代。

## 2.6 变量定义

变量定义格式：

```asm
变量名  变量定义伪指令  初值表
```

常用变量定义伪指令：

| MASM 类型 | 通用伪指令 | 大小 | 说明 |
|---|---|---|---|
| BYTE | DB | 1 字节 | 字节、字符、字符串 |
| WORD | DW | 2 字节 | 字、16 位整数 |
| DWORD | DD | 4 字节 | 双字、32 位整数或地址 |
| FWORD | DF | 6 字节 | 远指针等 |
| QWORD | DQ | 8 字节 | 64 位数据 |

例：

```asm
.data
bvar  byte 10, 20
wvar  word 100, -1
dvar  dword 1000, 2 dup(11223344h)
msg   byte 'Hello', 13, 10, 0
```

### 2.6.1 初值表

初值表用逗号分隔，可以包含：

- 数值常量；
- 字符常量；
- 字符串常量；
- `?`；
- `DUP`。

### 2.6.2 `?`

```asm
temp dword ?
```

表示分配空间但不关心初值。PPT 中指出实际填充可能为 0，但考试一般按“未显式赋初值”理解。

### 2.6.3 DUP 复制操作符

格式：

```asm
重复次数 dup(重复内容)
```

例：

```asm
buf byte 10 dup(0)        ; 10 个字节，均为 0
arr dword 3 dup(2,5)      ; 展开为 2,5,2,5,2,5，共 6 个 DWORD
```

高频题：

```asm
BUF DWORD 10h DUP(3 DUP(2,5), 3, 4, 5)
```

解析：

```text
3 DUP(2,5) = 6 个 DWORD
再加 3,4,5 = 3 个 DWORD
一组共 9 个 DWORD
10H = 16 组
总字节数 = 16 × 9 × 4 = 576 = 240H
```

答案：`240H`。

## 2.7 Intel 小端方式

注意：你原 md 中“Intel 小段方式存储”应改为 **Intel 小端方式存储 Little-endian**，它不是“分段存储”。

Intel 小端方式：

```text
低字节存放在低地址，高字节存放在高地址。
```

例：

```asm
wvar word 1234h
```

内存从低地址到高地址：

```text
34 12
```

例：

```asm
dvar dword 12345678h
```

内存从低地址到高地址：

```text
78 56 34 12
```

考试常让画内存存放图。

## 2.8 变量定位

### 2.8.1 ORG

```asm
org 100h
```

指定后续变量或代码从偏移地址 `100H` 开始安排。

### 2.8.2 ALIGN

```asm
align 4
```

使下一个变量从能被 4 整除的地址开始。

规则：

```text
地址 A 对齐 N 字节边界：A mod N = 0
```

常见：

- WORD 对齐偶地址；
- DWORD 对齐 4 字节边界；
- QWORD 对齐 8 字节边界。

## 2.9 变量属性和操作符

### 2.9.1 地址属性

| 操作符 | 含义 |
|---|---|
| `[ ]` | 把表达式作为存储器地址指针 |
| `$` | 当前偏移地址，通常表示下一个可用地址 |
| `OFFSET 变量名` | 取变量所在段内的偏移地址 |
| `SEG 变量名` | 取变量所在段基地址，主要用于实地址模型 |

例：

```asm
mov eax, [var]          ; 取 var 的内容
mov eax, var            ; MASM 中通常也是取 var 的内容
mov eax, offset var     ; 取 var 的偏移地址
```

### 2.9.2 类型属性

| 操作符 | 含义 |
|---|---|
| `PTR` | 临时指定内存操作数类型 |
| `TYPE 变量名` | 单个元素占用字节数 |
| `LENGTHOF 变量名` | 元素个数 |
| `SIZEOF 变量名` | 总字节数，等于 `TYPE × LENGTHOF` |

例：

```asm
array dword 10, 20, 30
```

```text
TYPE array     = 4
LENGTHOF array = 3
SIZEOF array   = 12
```

### 2.9.3 PTR

```asm
mov byte ptr [ebx], 255
mov word ptr [ebx], 255
mov dword ptr [ebx], 255
```

用于没有变量名、类型不明确的内存操作数。

## 2.10 数据寻址方式

PPT 主要分三大类：

1. 立即数寻址；
2. 寄存器寻址；
3. 存储器寻址。

### 2.10.1 立即数寻址

操作数是指令中直接给出的常数或地址常量。

```asm
mov eax, 10
mov ebx, offset var
```

注意：

```asm
MOV EBX, OFFSET VAR
```

源操作数是 **立即数寻址**，因为 `OFFSET VAR` 汇编后是一个地址常量。

### 2.10.2 寄存器寻址

操作数在寄存器中。

```asm
mov eax, ebx
add ecx, edx
```

### 2.10.3 存储器寻址

操作数在内存中。又可以细分为多种形式。

#### 直接寻址

```asm
mov eax, var
mov eax, [var]
```

直接通过变量名访问内存。

#### 寄存器间接寻址

```asm
mov esi, offset array
mov eax, [esi]
```

寄存器中保存内存地址。

#### 寄存器相对寻址

```asm
mov ax, var[ebx]
mov eax, [esi+4]
```

`VAR[EBX]` 等价于 `[VAR + EBX]`，源操作数是 **寄存器相对寻址**。你原 md 中写成“寄存器寻址”应修正。

#### 基址变址寻址

```asm
mov eax, [ebx+edi]
```

#### 相对基址变址寻址

```asm
mov var[ebx][edi], ax
```

等价于：

```asm
[var + ebx + edi]
```

目的操作数是 **相对基址变址寻址**。

#### 带比例因子的寻址

```asm
mov eax, array[esi*4]
mov eax, array[esi * type array]
```

有效地址公式：

```text
EA = 基址寄存器 + 变址寄存器 × 比例因子 + 位移量
```

比例因子只能是：

```text
1、2、4、8
```

适合访问 byte、word、dword、qword 数组元素。

## 2.11 本章速记


# 第三章：通用数据处理指令

## 3.1 本章复习定位

第三章是“指令系统”的核心，老师黑板重点包括：

- `MOV / XCHG / PUSH / POP`；
- 堆栈原理和无需显式 POP 的堆栈操作；
- MOV 指令双操作数限制；
- 算术运算、状态标志、进位和溢出区别；
- 位操作和移位指令；
- 状态标志如何随指令变化。

学习每条指令要掌握四件事：

1. 指令功能；
2. 支持的寻址方式；
3. 对标志位的影响；
4. 隐含使用的寄存器或特殊约定。

## 3.2 数据传送类指令

### 3.2.1 MOV 指令

格式：

```asm
mov dest, src
```

功能：

```text
dest <- src
```

注意：源操作数内容复制到目的操作数，源操作数不变。

### 3.2.2 MOV 指令限制

1. 立即数只能作为源操作数，不能作为目的操作数。

```asm
mov eax, 10      ; 正确
mov 10, eax      ; 错误
```

2. 两个操作数不能同时是存储器操作数。

```asm
mov [dest], [src]    ; 错误
mov eax, [src]       ; 正确
mov [dest], eax      ; 正确
```

3. 双操作数类型必须一致。

```asm
mov esi, dl      ; 错，32位 vs 8位
mov esi, edx     ; 对
mov al, 050ah    ; 错，050AH 超过 8 位范围
```

4. 内存操作数类型必须明确。

```asm
mov [ebx], 255              ; 错，类型不明确
mov byte ptr [ebx], 255     ; 对
mov word ptr [ebx], 255     ; 对
mov dword ptr [ebx], 255    ; 对
```

5. 立即数不能直接送段寄存器。

```asm
mov ds, @data   ; 错
mov ax, @data
mov ds, ax      ; 对
```

6. 段寄存器之间不能直接传送，通常要借助 AX。

```asm
mov ax, ds
mov es, ax
```

### 3.2.3 MOV 合法性高频题

| 指令 | 判断 | 原因 |
|---|---|---|
| `mov ecx, dx` | 错 | 类型不一致，ECX 32 位，DX 16 位 |
| `mov al, 300` | 错 | AL 8 位，300 超范围 |
| `mov 20h, ah` | 错 | 立即数不能作目的操作数 |
| `mov es, 1234h` | 错 | 立即数不能直接送段寄存器 |
| `mov es, ds` | 错 | 段寄存器之间不能直接传送 |
| `mov [edx], 10` | 错 | 内存操作数类型不明确 |
| `add ax, [esi][edi]` | 一般可按 `[esi+edi]` 理解，实际以 MASM 编译结果为准 | AX 可推断 WORD 类型，但写法兼容性依赖环境 |

## 3.3 XCHG 指令

格式：

```asm
xchg op1, op2
```

功能：交换两个操作数内容。

```asm
xchg eax, ebx
xchg eax, [var]
xchg al, [edi]
```

注意：

- 不能直接交换两个内存操作数；
- `xchg eax, eax` 可视为空操作 NOP。

常用于排序、数组逆序、两个变量交换。

## 3.4 堆栈操作指令 PUSH / POP

### 3.4.1 堆栈基本原理

堆栈是后进先出 LIFO/FILO 的存储区域。

- SS 指向堆栈段；
- ESP 指向当前栈顶；
- 栈顶在低地址方向；
- PUSH 后 ESP 减小；
- POP 后 ESP 增大。

### 3.4.2 PUSH

格式：

```asm
push src
```

32 位模式下压入双字：

```text
ESP = ESP - 4
SS:[ESP] = src
```

压入字量：

```text
ESP = ESP - 2
SS:[ESP] = src
```

### 3.4.3 POP

格式：

```asm
pop dest
```

32 位模式下弹出双字：

```text
dest = SS:[ESP]
ESP = ESP + 4
```

弹出字量：

```text
dest = SS:[ESP]
ESP = ESP + 2
```

### 3.4.4 堆栈应用

堆栈常用于：

1. 临时保存数据；
2. 子程序调用保存返回地址；
3. 参数传递；
4. 寄存器保护与恢复；
5. 中断和异常处理。

无需显式 `POP` 的堆栈操作：

- `CALL` 会自动把返回地址压栈；
- `RET` 会自动从栈顶弹出返回地址到 EIP；
- `INT / IRET` 也会自动利用堆栈保存/恢复现场。

### 3.4.5 例3-1 堆栈操作程序解析

```asm
dvar dword 67762000h,12345678h

mov eax, [dvar+4]     ; EAX=12345678H
push eax              ; 压入 12345678H
push dword ptr 10     ; 压入 0000000AH
push [dvar]           ; 压入 67762000H
pop eax               ; EAX=67762000H
pop [dvar+4]          ; [dvar+4]=0000000AH
mov ebx, [dvar+4]     ; EBX=0000000AH
pop ecx               ; ECX=12345678H
```

栈是后进先出，最后压入的最先弹出。

## 3.5 其他传送指令

### 3.5.1 LEA

格式：

```asm
lea reg, mem
```

功能：把内存操作数的有效地址 EA 送入寄存器，而不是取内存内容。

```asm
lea esi, var          ; ESI = var 的有效地址
mov edi, offset var   ; EDI = var 的偏移地址
```

区别：

- `OFFSET` 在汇编阶段取地址；
- `LEA` 在运行时计算有效地址；
- `LEA` 可计算复杂地址，如 `[esi+edi*4+100h]`。

### 3.5.2 XLAT

功能：

```text
AL <- [EBX + AL]
```

用于查表转换。

使用前：

- EBX 保存表首地址；
- AL 保存相对表首地址的位移。

例：数字转 ASCII：

```asm
num byte 6,7,7,8,3,0,0,0
tab byte '0123456789'

mov ebx, offset tab
mov al, [esi]
xlat                 ; AL = tab[AL]
```

## 3.6 标志操作指令

| 指令 | 功能 |
|---|---|
| CLC | CF=0 |
| STC | CF=1 |
| CMC | CF 取反 |
| CLD | DF=0，串操作地址递增 |
| STD | DF=1，串操作地址递减 |
| CLI | IF=0，禁止可屏蔽中断 |
| STI | IF=1，允许可屏蔽中断 |
| PUSHFD | EFLAGS 入栈 |
| POPFD | 从栈顶恢复 EFLAGS |

一般数据传送指令不影响状态标志，除了标志寄存器相关指令。

## 3.7 算术运算指令

### 3.7.1 ADD

```asm
add dest, src
; dest = dest + src
```

影响 CF、OF、ZF、SF、PF、AF。

### 3.7.2 ADC

```asm
adc dest, src
; dest = dest + src + CF
```

常用于多精度加法。

64 位加法模板：

```asm
mov eax, dword ptr [qvar1]       ; 低32位
add eax, dword ptr [qvar2]
mov edx, dword ptr [qvar1+4]     ; 高32位
adc edx, dword ptr [qvar2+4]
```

### 3.7.3 INC

```asm
inc reg/mem
; reg/mem = reg/mem + 1
```

影响 OF、SF、ZF、AF、PF，但 **不影响 CF**。

高频选择题：INC 除影响 SF、ZF 外，还影响 `OF、AF、PF`，不影响 CF。

### 3.7.4 SUB

```asm
sub dest, src
; dest = dest - src
```

影响 CF、OF、ZF、SF、PF、AF。

### 3.7.5 SBB

```asm
sbb dest, src
; dest = dest - src - CF
```

常用于多精度减法。

### 3.7.6 DEC

```asm
dec reg/mem
; reg/mem = reg/mem - 1
```

影响 OF、SF、ZF、AF、PF，但 **不影响 CF**。

### 3.7.7 NEG

```asm
neg dest
; dest = 0 - dest
```

用于求相反数/求补。

### 3.7.8 CMP

```asm
cmp op1, op2
; 计算 op1 - op2，只影响标志，不保存结果
```

高频题：

```asm
AX = 7836H
CMP AX, 9A5EH
```

执行后：

```text
AX = 7836H       ; CMP 不改变 AX
CF = 1           ; 无符号 7836H < 9A5EH，减法借位
OF = 1           ; 正数 - 负数 得到超范围正数，发生有符号溢出
```

## 3.8 乘除法指令

### 3.8.1 MUL 无符号乘法

隐含使用累加器。

| 操作数大小 | 被乘数 | 乘积 |
|---|---|---|
| 8位 | AL | AX |
| 16位 | AX | DX:AX |
| 32位 | EAX | EDX:EAX |

### 3.8.2 IMUL 有符号乘法

用于有符号乘法，结果位置与 MUL 类似。

### 3.8.3 DIV 无符号除法

| 除数大小 | 被除数 | 商 | 余数 |
|---|---|---|---|
| 8位 | AX | AL | AH |
| 16位 | DX:AX | AX | DX |
| 32位 | EDX:EAX | EAX | EDX |

32 位除法前常见：

```asm
xor edx, edx
mov eax, 被除数
mov ebx, 除数
div ebx
```

### 3.8.4 IDIV 有符号除法

有符号除法前要做符号扩展：

```asm
cdq        ; EAX 符号扩展到 EDX:EAX
idiv ebx
```

## 3.9 状态标志与算术运算

### 3.9.1 CF

无符号加减结果超出范围时置 1。

### 3.9.2 OF

有符号加减结果超出范围时置 1。

人工判断溢出：

- 两个同号数相加，结果符号与原数不同，则溢出；
- 两个异号数相减，结果符号不合理，也可能溢出。

### 3.9.3 ZF

结果为 0 时置 1。

### 3.9.4 SF

结果最高位为 1 时置 1。

### 3.9.5 PF

结果最低字节中 1 的个数为偶数或 0 时置 1。

## 3.10 逻辑运算指令

| 指令 | 功能 | 常用用途 |
|---|---|---|
| AND | 按位与 | 清零某些位、测试掩码 |
| OR | 按位或 | 置位 |
| XOR | 按位异或 | 取反某些位、清零寄存器、简单加密 |
| NOT | 按位取反 | 各位取反 |
| TEST | 按位与但不保存结果 | 测试某些位 |

常见：

```asm
xor eax, eax      ; EAX 清零
and al, 5fh       ; 小写转大写
or al, 20h        ; 大写转小写
test eax, 02h     ; 测试 D1 位
```

逻辑运算一般使 CF=0、OF=0，并根据结果设置 ZF、SF、PF。`NOT` 一般不影响标志。

## 3.11 移位和循环移位指令

### 3.11.1 逻辑移位

```asm
shl dest, count    ; 逻辑左移，低位补0
shr dest, count    ; 逻辑右移，高位补0
```

- `SHL` 左移 n 位相当于无符号乘以 `2^n`；
- `SHR` 右移 n 位相当于无符号除以 `2^n`；
- 移出的最后一位进入 CF。

例：EDX 中无符号数除以 16：

```asm
shr edx, 4
```

### 3.11.2 算术移位

```asm
sal dest, count    ; 算术左移，同 SHL
sar dest, count    ; 算术右移，保持符号位
```

`SAR` 用于有符号数除以 `2^n`。

### 3.11.3 循环移位

```asm
rol dest, count
ror dest, count
rcl dest, count
rcr dest, count
```

`RCR/RCL` 会把 CF 作为循环链的一部分。

例：64 位逻辑右移 1 位：

```asm
shr edx, 1
rcr eax, 1
```

用于把 `EDX:EAX` 整体右移。

## 3.12 本章速记

```text
MOV：不能内存到内存，不能立即数到段寄存器，类型要一致，内存类型要明确
PUSH：ESP先减，再写栈；POP：先读栈，再ESP加
CALL/RET 会自动使用堆栈保存/恢复返回地址
LEA 取有效地址，OFFSET 取汇编期偏移地址
XLAT：AL = [EBX + AL]
INC/DEC 不影响 CF
CMP 不保存结果，只设置标志
ADD/SUB 看 CF 判断无符号越界，看 OF 判断有符号溢出
DIV 前无符号清 EDX；IDIV 前用 CDQ
SHR 除以2^n，SHL 乘以2^n
```

# 第四章：程序结构

第四章是考试程序题和应用题的核心。本章以三种程序结构为主线：

老师黑板重点包括：

- 4.2 / 4.3 分支结构和循环结构；

- LOOP 指令；
- 减量控制循环、增量控制循环；

## 4.2 顺序程序结构

顺序结构就是按照指令书写顺序逐条执行。它是分支体和循环体的基础。

### 4.2.1 例4-1 自然数求和

题目：求 `1+2+...+N`。

公式：

```text
1 + 2 + ... + N = (1 + N) × N / 2
```

代码核心：

```asm
num dd 3456
sum dq 0

mov eax, [num]              ; EAX=N
add eax, 1                  ; EAX=N+1
imul dword ptr [num]        ; EDX:EAX=(N+1)*N
shr edx, 1                  ; 64位整体右移，高32位先右移
rcr eax, 1                  ; CF进入EAX最高位
mov dword ptr [sum], eax    ; 低32位
mov dword ptr [sum+4], edx  ; 高32位
```

考点：

- `IMUL` 结果在 `EDX:EAX`；
- 64 位右移要用 `SHR EDX / RCR EAX`；
- `sum dq` 是 64 位变量；
- 小端方式低位存低地址。

### 4.2.2 例4-2 CPUID 处理器识别

当 `EAX=0` 执行 `CPUID`，厂商字符串通过：

```text
EBX、EDX、ECX
```

返回。Intel 厂商字符串：

```text
GenuineIntel
```

## 4.3 控制转移基础

处理器通过 `CS:EIP` 取得下一条指令。

- 顺序执行：EIP 自动增加；
- 段内转移：只改变 EIP；
- 段间转移：同时改变 CS 和 EIP。

控制转移类指令本质：改变程序执行顺序，即改变 EIP 或 CS:EIP。

## 4.4 JMP 无条件转移

格式：

```asm
jmp label
jmp eax
jmp near ptr [nvar]
```

三类指令寻址：

| 指令 | 指令寻址方式 | 含义 |
|---|---|---|
| `jmp label` | 相对寻址 | 目标地址由当前 EIP + 位移量得到 |
| `jmp eax` | 寄存器间接寻址 | EAX 中保存目标偏移地址 |
| `jmp near ptr [nvar]` | 存储器间接寻址 | 内存单元中保存目标偏移地址 |

相对转移目标地址：

```text
目标地址 = JMP 下一条指令地址 + 位移量
```

例：JMP NEAR 在 `23000H`，指令长度 3，位移量 `4010H`：

```text
目标地址 = 23000H + 3 + 4010H = 27013H
```

## 4.5 条件转移 Jcc

格式：

```asm
jcc label
```

条件满足则转移，否则顺序执行下一条。

条件转移指令不影响标志，只读取标志。

形成条件的常用指令：

- `CMP`；
- `TEST`；
- `ADD/SUB`；
- `AND/OR/XOR`；
- `SHL/SHR` 等。

## 4.6 单个标志状态作为条件的转移指令

| 指令 | 条件 | 含义 |
|---|---|---|
| JZ / JE | ZF=1 | 结果为 0 / 相等 |
| JNZ / JNE | ZF=0 | 结果非 0 / 不相等 |
| JS | SF=1 | 结果为负 |
| JNS | SF=0 | 结果非负 |
| JO | OF=1 | 有溢出 |
| JNO | OF=0 | 无溢出 |
| JP / JPE | PF=1 | 偶校验 |
| JNP / JPO | PF=0 | 奇校验 |
| JC | CF=1 | 有进位/借位 |
| JNC | CF=0 | 无进位/借位 |

记忆：带 `N` 的转移指令，一般表示对应条件“不成立”或对应标志位为 0。

高频题：

```asm
jnz label
```

条件：

```text
ZF = 0
```

## 4.7 两数大小关系作为条件的转移指令

### 4.7.1 无符号比较：Above / Below

| 指令 | 条件 | 含义 |
|---|---|---|
| JA / JNBE | CF=0 且 ZF=0 | 无符号大于 |
| JAE / JNB | CF=0 | 无符号大于等于 |
| JB / JNAE | CF=1 | 无符号小于 |
| JBE / JNA | CF=1 或 ZF=1 | 无符号小于等于 |

### 4.7.2 有符号比较：Greater / Less

| 指令 | 条件 | 含义 |
|---|---|---|
| JG / JNLE | SF=OF 且 ZF=0 | 有符号大于 |
| JGE / JNL | SF=OF | 有符号大于等于 |
| JL / JNGE | SF≠OF | 有符号小于 |
| JLE / JNG | SF≠OF 或 ZF=1 | 有符号小于等于 |

### 高频判断

```text
无符号数大小比较：JA/JAE/JB/JBE
有符号数大小比较：JG/JGE/JL/JLE
相等/不等：JE/JNE，不分有符号和无符号
```

例：A、B 是有符号数，A>=B 时转移，用：

```asm
jge label
```

## 4.8 19 个转移类指令整理

老师黑板写“19 个转移类指令”，可按如下理解：

### 1 个无条件转移

```text
JMP
```

### 10 个单标志条件转移码

```text
JZ/JE      ZF=1
JNZ/JNE    ZF=0
JS         SF=1
JNS        SF=0
JO         OF=1
JNO        OF=0
JP/JPE     PF=1
JNP/JPO    PF=0
JC         CF=1
JNC        CF=0
```

注意：`JE` 是 `JZ` 的同义写法，`JNE` 是 `JNZ` 的同义写法，`JP/JPE`、`JNP/JPO` 也是同义组。

### 8 个大小关系条件转移码

```text
无符号：JA、JAE、JB、JBE
有符号：JG、JGE、JL、JLE
```

你原 md 中把 `JG/JL` 放进“单个状态标志”类别不准确，应改为“有符号大小关系转移”。

## 4.9 单分支结构

高级语言：

```c
if (condition) {
    body;
}
```

汇编模板：

```asm
    cmp/test ...
    jcc skip
    ; 分支体
skip:
```

汇编中经常“条件满足则跳过分支体”，与高级语言 if 的直观方向相反。

### 例4-9 求绝对值

```asm
call readsid
cmp eax, 0
jge nonneg       ; EAX>=0，不用处理
neg eax          ; EAX<0，求相反数
nonneg:
call dispuid
```

考点：

- 有符号数比较用 G/L 系列；
- `NEG` 求补，即 `0 - 操作数`。

### 例4-10 大写字母转小写

```asm
call readc
cmp al, 'A'
jb done
cmp al, 'Z'
ja done
or al, 20h
call dispc
done:
```

考点：

- ASCII 按无符号数比较，用 A/B 系列；
- 大写转小写可 `OR 20H` 或 `ADD 20H`。

## 4.10 双分支结构

高级语言：

```c
if (condition) {
    branch1;
} else {
    branch2;
}
```

汇编模板：

```asm
    cmp/test ...
    jcc branch2

branch1:
    ; 分支1
    jmp done

branch2:
    ; 分支2

done:
```

重点：顺序执行的分支体最后必须有 `JMP done` 跳过另一个分支，否则两个分支可能都被执行。

### 例4-6 位测试

测试 EAX 的 D1 位。

```asm
mov eax, 56h
test eax, 02h
jz nom
mov eax, offset yes_msg
jmp done
nom:
mov eax, offset no_msg
done:
call dispmsg
```

解析：

- `TEST` 做按位与但不保存结果；
- `02H = 00000010B`，用于测试 D1 位；
- D1=0 时结果为 0，ZF=1，`JZ nom`。

### 例4-7 奇校验

```asm
and al, 7fh
jnp next
or al, 80h
next:
```

解析：

- `AND AL,7FH` 先把最高位置 0；
- PF=0 表示最低字节中 1 的个数为奇数；
- `JNP` 即 PF=0，已有奇数个 1，不用设置最高位；
- 若 1 的个数为偶数，则 `OR AL,80H` 把最高位置 1，使总数变为奇数。

## 4.11 多分支结构

多分支由多个判断和多个分支体构成。常见结构：

```asm
    cmp eax, 0
    je zero
    jg positive

negative:
    ; eax < 0
    jmp done

zero:
    ; eax = 0
    jmp done

positive:
    ; eax > 0

done:
```

注意：每个分支执行完通常都要 `JMP done` 到共同出口。

### 例4-8 两个有符号数比较

```asm
cmp ebx, ecx
jne nequal
; 相等
jmp done

nequal:
jl first          ; EBX<ECX，不交换
xchg ebx, ecx     ; 否则交换，使 EBX 为较小值
first:
; 显示 EBX 和 ECX

done:
```

考点：

- 相等用 `JE/JNE`，不分有无符号；
- 有符号大小比较用 `JL/JG/JGE/JLE`；
- `XCHG` 可交换两个寄存器。

## 4.12 其他分支例题

### 例4-5 个数折半

```asm
mov eax, 885
shr eax, 1
jnc goeven
add eax, 1
goeven:
call dispuid
```

解析：

- `SHR EAX,1` 后，原最低位进入 CF；
- 原数偶数：CF=0，无余数；
- 原数奇数：CF=1，有余数，需要商加 1。

无分支优化：

```asm
shr eax, 1
adc eax, 0
```

因为 `ADC` 会把 CF 加到 EAX 中。

### 例4-11 显示最高位

```asm
mov ebx, dvar
shl ebx, 1
jc one
mov al, '0'
jmp two
one:
mov al, '1'
two:
call dispc
```

解析：

- `SHL EBX,1` 会把原最高位移入 CF；
- `JC one` 判断最高位是否为 1。

### 例4-12 有符号数运算溢出

```asm
mov eax, dvar1
sub eax, dvar2
jo error
mov dvar3, eax
jmp done
error:
; 溢出处理
done:
```

解析：

- 有符号数运算是否溢出看 OF；
- `JO` 表示 OF=1 时转移。

## 4.13 循环程序结构

循环结构由三部分组成：

1. 循环初始化；
2. 循环体；
3. 循环控制。

分类：

- 计数控制循环：循环次数已知；
- 条件控制循环：循环次数未知，但结束条件已知；
- 多重循环：循环中嵌套循环。

## 4.14 LOOP 指令

格式：

```asm
loop label
```

等价于：

```asm
dec ecx
jnz label
```

准确过程：

```text
ECX = ECX - 1
若 ECX != 0，则跳转
若 ECX == 0，则顺序执行下一条
```

注意：`LOOP` 不影响标志位。

### 高频陷阱

如果 ECX 初值为 0：

```asm
mov ecx, 0
again:
    ; 循环体
    loop again
```

循环不是 0 次，而是 `2^32` 次，因为 ECX 先减为 `FFFFFFFFH`。

如果 ECX 初值为 -10，循环 `2^32 - 10` 次。

### JECXZ

```asm
jecxz done
```

含义：若 ECX=0，则跳转。它直接检查 ECX，不依赖标志位。

可用于 LOOP 前防止 ECX=0：

```asm
mov ecx, lengthof array
jecxz done
again:
    ; 循环体
    loop again
done:
```

## 4.15 计数控制循环

### 例4-14 数组求和

```asm
.data
array dword 136, -138, 133, 130, -161
sum   dword ?

.code
    mov ecx, lengthof array
    xor eax, eax
    xor ebx, ebx

again:
    add eax, array[ebx * type array]
    inc ebx
    loop again

    mov sum, eax
```

寄存器分配：

| 寄存器 | 作用 |
|---|---|
| ECX | 循环次数 |
| EAX | 累加和 |
| EBX | 数组下标 |

数组寻址：

```asm
array[ebx * type array]
```

如果 `array dword`，`type array=4`。

### 减量控制改增量控制

LOOP 是减量控制。也可用增量控制：

```asm
    xor ebx, ebx
    xor eax, eax

again:
    add eax, array[ebx * type array]
    inc ebx
    cmp ebx, lengthof array
    jb again

    mov sum, eax
```

## 4.16 条件控制循环

条件控制循环模板：

```asm
again:
    cmp/test 条件
    jcc done

    ; 循环体

    jmp again

done:
```

### 例4-17 字符串长度统计

```asm
string byte 'Do you have fun with Assembly?', 0

xor ebx, ebx
again:
    mov al, string[ebx]
    cmp al, 0
    jz done
    inc ebx
    jmp again

done:
    mov eax, ebx
```

解析：

- EBX 既作下标又作计数器；
- 遇到 0 字符结束；
- 这是典型 while 循环。

### 例4-18 Fibonacci 数列

```asm
mov eax, 1
call dispuid
call dispuid
mov ebx, eax

again:
    add eax, ebx
    jc done
    call dispuid
    xchg eax, ebx
    jmp again

done:
```

解析：

- EAX 和 EBX 保存相邻两项；

# 第五章：模块化程序设计

## 5.1 本章复习定位

第五章重点是子程序。老师黑板重点包括：

1. 处理子程序的一些指令；
2. 子程序定义的伪指令；
3. 子程序传参的三种方式。

PPT 中本章内容包括：

- 子程序结构；
- CALL / RET；
- PROC / ENDP；
- 寄存器传参；
- 共享变量传参；
- 堆栈传参；
- 多模块程序结构和与 C++ 混合编程。

考试重点主要是前两节：子程序结构和参数传递。

## 5.2 子程序基本概念

子程序也叫：

```text
Subroutine = Function = Procedure
```

作用：

- 把重复功能封装起来；
- 程序结构清晰；
- 便于维护；
- 便于多人协作。

子程序运行过程：

```text
主程序 CALL 子程序
子程序执行
子程序 RET 返回主程序
```

## 5.3 CALL 指令

格式：

```asm
call label
call reg32
call mem32
```

功能：

1. 把 CALL 下一条指令的地址压入堆栈，作为返回地址；
2. 跳转到子程序入口。

段内调用：

```text
push EIP
EIP = 子程序地址
```

段间调用：

```text
push CS
push EIP
CS:EIP = 子程序地址
```

本课程一般主要关注段内调用。

## 5.4 RET 指令

格式：

```asm
ret
ret i16
```

功能：从堆栈弹出返回地址，送入 EIP。

```text
EIP = SS:[ESP]
ESP = ESP + 4
```

`RET i16` 还会额外使 ESP 加上 i16，用于清理参数。

## 5.5 CALL / RET 与堆栈

思考题：

```asm
call next
next:
    pop eax
```

执行后：

```text
EAX = next 标号处的偏移地址
```

原因：`CALL next` 会把下一条指令地址压栈，而下一条指令正是 `next: pop eax`。

## 5.6 PROC / ENDP 过程定义伪指令

格式：

```asm
过程名 proc
    ; 过程体
    ret
过程名 endp
```

例：

```asm
subp proc
    ; 子程序代码
    ret
subp endp
```

`PROC` 后可加 `NEAR` 或 `FAR`，一般简化段定义中不需要显式写。

## 5.7 例5-1 子程序调用与返回地址

主程序：

```asm
mov eax, 1
mov ebp, 5
call subp
retp1: mov ecx, 3
retp2: mov edx, 4
```

子程序：

```asm
subp proc
    push ebp
    mov ebp, esp
    mov esi, [ebp+4]       ; ESI = 返回地址 retp1
    mov edi, offset retp2  ; EDI = retp2 地址
    mov ebx, 2
    pop ebp
    ret
subp endp
```

解析：

进入子程序后：

```text
[EBP]   = 原 EBP
[EBP+4] = CALL 压入的返回地址
```

如果增加：

```asm
mov [ebp+4], edi
```

则 `RET` 时返回地址被改成 `retp2`，程序会跳到 `retp2`。

## 5.8 子程序设计注意事项

1. 用 `PROC/ENDP` 定义子程序；
2. 主程序用 `CALL` 调用，子程序用 `RET` 返回；
3. `PUSH/POP` 要成对使用，保持堆栈平衡；
4. 子程序中修改过且主程序还需要的寄存器，要保护和恢复；
5. 出口参数/返回值寄存器不能被恢复覆盖；
6. 子程序应安排在主程序之外；
7. 子程序可以嵌套和递归；
8. 必须处理好参数传递。

### 重要易错点

如果 EAX 用作返回值，则不要这样写：

```asm
push eax
; 计算返回值到 eax
pop eax        ; 错，会把返回值覆盖掉
ret
```

返回值寄存器不能在返回前被恢复为旧值。

## 5.9 例5-2 回车换行子程序

```asm
dpcrlf proc
    push eax
    mov al, 0dh
    call dispc
    mov al, 0ah
    call dispc
    pop eax
    ret
dpcrlf endp
```

解析：

- 子程序内部使用 AL；
- 为避免影响主程序的 EAX，开头 `push eax`，结尾 `pop eax`；
- 子程序中可以调用另一个子程序，即子程序嵌套。

## 5.10 参数传递

主程序和子程序之间通过参数建立联系。

参数分为：

- 入口参数：主程序传给子程序；
- 出口参数：子程序返回给主程序，也叫返回值。

传递内容可以是：

- 数值 By Value；
- 地址 By Location。

三种参数传递方法：

1. 寄存器传递；
2. 共享变量传递；
3. 堆栈传递。

## 5.11 寄存器传递参数

特点：

- 简单、快速；
- 适合少量参数；
- 大量数据通常传地址；
- 返回值常用 EAX/AX/AL。

例5-3 十六进制数码转 ASCII 子程序：

主程序片段：

```asm
mov eax, 1234abcdh
xor ebx, ebx
mov ecx, 8
again:
    rol eax, 4
    push eax
    call htoasc
    mov regd+4[ebx], al
    pop eax
    inc ebx
    dec ecx
    jnz again
```

子程序：

```asm
htoasc proc
    and al, 0fh
    or al, 30h
    cmp al, 39h
    jbe htoend
    add al, 7
htoend:
    ret
htoasc endp
```

解析：

- 入口参数：AL 低 4 位；
- 出口参数：AL；
- `0~9` 转 ASCII：加 `30H`；
- `A~F` 转 ASCII：先加 `30H` 后再加 7；
- 主程序用 `push eax / pop eax` 保存原始 EAX，因为 EAX 中还存着待转换数据。

## 5.12 共享变量传递参数

共享变量传参就是主程序和子程序访问同一个变量。

特点：

- 类似高级语言全局变量；
- 简单；
- 子程序通用性较差；
- 多模块时需 `PUBLIC/EXTERN` 声明。

例5-5 二进制输入：

```asm
count = 5
array dword count dup(0)
temp  dword ?

mov ecx, count
mov ebx, offset array
again:
    call rdbd
    mov eax, [temp]
    mov [ebx], eax
    add ebx, 4
    loop again
```

子程序 `rdbd` 把结果放入共享变量 `temp`。

二进制字符转换核心：

```asm
sub al, '0'     ; '0'/'1' -> 0/1
shl ebx, 1      ; 旧结果左移一位
or bl, al       ; 拼接新位
```

## 5.13 堆栈传递参数

最规范、最接近 C 语言函数调用。

调用者：

```asm
push 参数2
push 参数1
call subp
add esp, 8      ; 调用者清理参数，视约定而定
```

子程序：

```asm
subp proc
    push ebp
    mov ebp, esp

    mov eax, [ebp+8]     ; 第一个参数
    mov ebx, [ebp+12]    ; 第二个参数

    pop ebp
    ret
subp endp
```

为什么第一个参数是 `[EBP+8]`？

```text
[EBP]   = 原 EBP
[EBP+4] = 返回地址
[EBP+8] = 第一个参数
[EBP+12]= 第二个参数
```

## 5.14 例5-7 计算有符号数组平均值

主程序：

```asm
push lengthof array
push offset array
call mean
add esp, 8
; EAX = 平均值
```

子程序框架：

```asm
mean proc
    push ebp
    mov ebp, esp

    mov ebx, [ebp+8]     ; 数组地址
    mov ecx, [ebp+12]    ; 元素个数

    xor eax, eax         ; sum
    xor edx, edx         ; index
again:
    add eax, [ebx+edx*4]
    inc edx
    loop again

    mov ecx, [ebp+12]
    cdq
    idiv ecx             ; 有符号除法

    pop ebp
    ret
mean endp
```

注意：

- 有符号除法前用 `CDQ`；
- EAX 保存和，也保存最终平均值；
- 若元素个数为 0，会发生除零错误；
- 求和可能溢出。

## 5.15 子程序调用方式与参数传递方式的区别

你原 md 中写“子程序调用的三种方式：直接调用、间接调用、递归调用”，这可以作为 CALL 使用方式补充，但老师黑板重点更可能是“子程序传参的三种方式”。二者不要混淆。

### CALL 的调用方式

```asm
call subp       ; 直接调用
call eax        ; 寄存器间接调用
call [mem]      ; 存储器间接调用
```

递归调用是子程序自己调用自己，是程序结构形式，不是参数传递方式。

### 参数传递三种方式

```text
寄存器传参
共享变量传参
堆栈传参
```

## 5.16 上机实验中与第五章相关的程序题

### 5.16.1 阶乘子程序

任务：写求 `n!` 的子程序，用它求：

```text
1! + 2! + ... + 8! = 46233
```

要求比较三种参数传递方法：

- 寄存器；
- 共享变量；
- 堆栈。

### 5.16.2 Fibonacci 前 20 项

递推：

```text
f1 = 1, f2 = 1, fn = f(n-1) + f(n-2)
```

32 位无符号不溢出最大项：

```text
F(47)=2971215073 可以
F(48)=4807526976 溢出
```

所以无符号最大 n=47。有符号 32 位最大 n=46。

### 5.16.3 GCD 最大公约数子程序

欧几里得算法：

```text
gcd(a,0)=a
gcd(a,b)=gcd(b,a mod b)
```

核心：

```asm
again:
    cmp ecx, 0
    je done
    xor edx, edx
    div ecx          ; EDX = a mod b
    mov eax, ecx     ; a = b
    mov ecx, edx     ; b = r
    jmp again
done:
    ; EAX = gcd
```

合理寄存器分配：

```text
EAX = a
ECX = b
EDX:EAX = 被除数
EDX = 余数
```

### 5.16.4 Bubble 冒泡排序子程序

要求：主子程序参数通过堆栈传递，子程序处理一维数组时只能采用间接寻址。

算法：

```text
外循环：控制趟数
内循环：相邻元素比较和交换
```

核心思想：

```asm
cmp [esi], [esi+4]
jle no_swap
; 交换 [esi] 和 [esi+4]
no_swap:
add esi, 4
```

注意：子程序中不要直接写 `array[esi*4]`，因为题目要求只能间接寻址，应使用 `[esi]`、`[esi+4]`。
