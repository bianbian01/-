## 一、整门课总主线

操作系统整门课，本质上就在讲 6 件事：

1. 操作系统是什么，为什么需要它
2. CPU 怎么分给多个程序
3. 多个进程怎么配合、怎么避免冲突
4. 内存怎么分、地址怎么转、页面怎么换
5. 外设怎么管、磁盘怎么调度
6. 文件怎么组织、怎么存、怎么找

整门课高分区主要集中在：

1. 第2章 进程与调度
2. 第3章 PV 操作与死锁
3. 第4章 存储管理
4. 第5章 磁盘调度

第1章和第6章分值通常略低，但送分题很多，不能丢。

## 二、第1章 引论必背

### 1. 操作系统定义

操作系统是管理和控制计算机软硬件资源、组织程序运行、并为用户和应用程序提供接口的系统软件。

一句话记忆：

`OS = 管资源 + 控运行 + 给接口`

### 2. 操作系统设计目标

- 方便性
- 有效性
- 可扩充性
- 可移植性
- 可靠性
- 开放性

口诀：

`方效扩移靠开`

### 3. 操作系统主要功能

- 处理机管理
- 存储管理
- 设备管理
- 文件管理
- 用户接口

一句话记忆：

`管CPU、管内存、管设备、管文件、给接口`

### 4. 操作系统基本特征

- 并发
- 共享
- 虚拟
- 异步

口诀：

`并共享虚异`

### 5. 并发与并行

- 并发：多个程序在一段时间内交替推进
- 并行：多个程序在同一时刻真正同时执行

### 6. 用户态与内核态

划分原因：

- 保证系统安全性
- 保证系统可靠性
- 保护系统资源
- 防止用户程序滥用特权指令

标准答法：

操作系统划分用户态和内核态，是为了保证系统安全性和可靠性，保护系统资源，防止用户程序随意执行特权操作。

### 7. 特权指令

特权指令：只能在内核态执行的指令。  
常见：I/O 指令、修改中断状态、设置系统状态。

### 8. PSW

PSW = Program Status Word = 程序状态字  
记录程序运行状态、条件码、中断状态、CPU 状态等信息。

### 9. 中断

中断处理三步：

1. 保护现场
2. 处理中断
3. 恢复现场

### 10. 通道

通道是专门处理 I/O 设备数据传输的处理器。  
它不同于普通 CPU，没有独立内存空间，需要使用主存。

### 11. 多道程序设计硬件基础

`中断 + 通道`

## 三、第2章 进程管理与调度必背

### 1. 程序、作业、进程、线程

- 程序：静态，放在外存中的代码
- 作业：用户提交给系统的一项任务
- 进程：程序关于某数据集合的一次执行过程
- 线程：进程内一个相对独立的执行流

一句话记忆：

`程序静态，进程动态；用户交作业，系统建进程，CPU调线程`

### 2. 进程定义

进程是程序关于某个数据集合的一次执行过程，是操作系统进行资源分配和保护的基本单位。

### 3. 进程实体

`进程实体 = 程序段 + 数据段 + PCB`

### 4. PCB

PCB = Process Control Block = 进程控制块  
保存进程标识、状态、调度信息、资源信息、现场信息等。  
PCB 是进程存在的唯一标志。

### 5. 进程特征

- 动态性
- 并发性
- 独立性
- 异步性
- 结构性

口诀：

`动并独异结`

### 6. 进程三态

- 就绪态
- 运行态
- 阻塞态

状态转换：

- 就绪 -> 运行：获得 CPU
- 运行 -> 就绪：时间片用完或被抢占
- 运行 -> 阻塞：请求 I/O 或等待事件
- 阻塞 -> 就绪：等待事件完成

重点：

`阻塞不能直接到运行，必须先回就绪`

### 7. 原语与原子性

- 原语：操作系统中执行时不可中断的程序段
- 原子性：要么不做，要做就一次做完，中间不能被打断

### 8. 作业组成

- 程序
- 数据
- 作业说明书

### 9. 三级调度

- 高级调度：作业调度，从外存后备队列选作业进入内存
- 中级调度：内存调度，负责挂起与激活
- 低级调度：进程调度，从就绪队列选进程占用 CPU

口诀：

`高作业、中挂激、低选CPU`

### 10. 抢占式与非抢占式

- 非抢占式：进程完成或主动放弃 CPU 后才切换
- 抢占式：系统可强行剥夺 CPU

### 11. 调度算法

- FCFS：先来先服务
- SJF：短作业优先
- HRRN：高响应比优先
- RR：时间片轮转

### 12. 调度公式

```text
完成时间 = 进程结束运行的时刻
周转时间 = 完成时间 - 到达时间
带权周转时间 = 周转时间 / 服务时间
响应比 = (等待时间 + 服务时间) / 服务时间
```

### 13. 线程与进程区别

- 进程：资源分配的基本单位
- 线程：CPU 调度的基本单位

一句话记忆：

`进程分资源，线程上CPU`

## 四、第3章 进程同步、通信与死锁必背

### 1. 同步与互斥

- 同步：多个进程之间有先后顺序或协作关系
- 互斥：多个进程不能同时访问同一临界资源

口诀：

`同步看先后，互斥看共享`

### 2. 临界资源与临界区

- 临界资源：一次只允许一个进程访问的资源
- 临界区：访问临界资源的代码段

口诀：

`资源是东西，区是代码`

### 3. 临界区访问原则

1. 空闲让进
2. 忙则等待
3. 有限等待
4. 让权等待

口诀：

`空进忙等，有限让权`

### 4. 信号量与 P/V 操作

- P(S)：申请资源，S = S - 1；若 S < 0，则阻塞
- V(S)：释放资源，S = S + 1；若 S <= 0，则唤醒等待进程

口诀：

`P减申请，V加释放`

### 5. 前驱关系模板

如果 A 必须在 B 前执行：

```text
semaphore s = 0;

A:
  A;
  V(s);

B:
  P(s);
  B;
```

口诀：

`s=0，前V后P`

### 6. 生产者-消费者模板

```text
semaphore mutex = 1;
semaphore empty = n;
semaphore full = 0;

producer:
  生产
  P(empty)
  P(mutex)
  放入缓冲区
  V(mutex)
  V(full)

consumer:
  P(full)
  P(mutex)
  取出产品
  V(mutex)
  V(empty)
  消费
```

初值记忆：

`mutex = 1, empty = n, full = 0`

### 7. 读者-写者

- 读读共享
- 写写互斥
- 读写互斥

### 8. 哲学家进餐

重点：理解死锁风险  
常见解法：

- 最多允许 4 个哲学家同时拿筷子
- 奇偶哲学家相反顺序拿筷子

### 9. 死锁定义

死锁是多个进程因竞争资源而相互等待，若无外力作用都不能继续推进的现象。

### 10. 死锁四个必要条件

1. 互斥
2. 不剥夺
3. 请求并保持
4. 循环等待

口诀：

`互不请环`

### 11. 安全状态与不安全状态

- 安全状态：存在一个安全序列，使所有进程都能顺利完成
- 不安全状态：不存在安全序列，但不一定已经死锁

重点：

`不安全 ≠ 已死锁`

### 12. 银行家算法核心

- Available：系统可用资源
- Max：最大需求
- Allocation：已分配资源
- Need = Max - Allocation

判断步骤：

1. 先算 Need
2. 看 Need <= Work 的进程
3. 能完成就归还 Allocation
4. 继续找，直到找到安全序列或找不到

## 五、第4章 存储管理必背

### 1. 逻辑地址与物理地址

- 逻辑地址：程序使用的地址
- 物理地址：内存中的实际地址

口诀：

`逻辑给程序，物理给内存`

### 2. 重定位

- 静态重定位：程序装入内存时一次完成地址转换
- 动态重定位：程序运行时进行地址转换

口诀：

`静态装入时改，动态运行时改`

### 3. 连续分配

- 单一连续分配
- 固定分区分配
- 可变分区分配

### 4. 可变分区算法

- FF：首次适应
- NF：循环首次适应
- BF：最佳适应
- WF：最坏适应

### 5. 分页

- 逻辑地址 = 页号 P + 页内位移 W
- 物理地址 = 块号 F + 页内位移 W

公式：

```text
页号 = A / 页面大小
页内位移 = A % 页面大小
物理地址 = F × 页面大小 + W
```

注意：

`1KB = 1024B`

### 6. 分段

- 逻辑地址 = 段号 S + 段内位移 W
- 物理地址 = 段基址 + 段内位移

步骤：

1. 先查段号是否合法
2. 再判断段内位移是否越界
3. 最后算物理地址

### 7. 分页与分段区别

- 页是物理单位，段是逻辑单位
- 页大小固定，段长度不固定
- 分页地址空间一维，分段地址空间二维
- 分页便于系统管理，分段更符合程序逻辑

口诀：

`页固定，段不固定；页偏物理，段偏逻辑`

### 8. 段页式

`先分段，再分页`

地址转换步骤：

1. 查段表
2. 再查该段对应的页表
3. 找到物理块号
4. 算物理地址

### 9. 虚拟存储与局部性

- 虚拟存储：把内存和外存结合起来，使用户感觉内存更大
- 时间局部性：刚访问过的内容近期还可能再次访问
- 空间局部性：刚访问过的位置附近内容近期还可能被访问

### 10. 页面置换算法

- FIFO：淘汰最早进入内存的页
- OPT：淘汰未来最长时间不再使用的页
- LRU：淘汰最近最长时间未使用的页

口诀：

- `FIFO看最早进`
- `OPT最优但不可实现`
- `LRU看最近最久没用`

### 11. 缺页率

```text
缺页率 = 缺页次数 / 访问总次数
```

## 六、第5章 设备管理必背

### 1. 设备分类

- 独占设备
- 共享设备
- 虚拟设备

### 2. 四种 I/O 控制方式

1. 程序直接控制
2. 中断控制
3. DMA
4. 通道

CPU 负担大小规律：

`程序直接控制 > 中断控制 > DMA > 通道`

### 3. DMA

DMA：设备和内存之间直接传送数据，CPU 只负责初始化和结束处理。

### 4. 通道

通道是专门处理 I/O 数据传输的处理器。  
它没有独立内存空间，需要使用主存。

### 5. Cache 与缓冲区

- Cache：缓解 CPU 与主存速度差，存放主存副本
- 缓冲区：缓解 I/O 设备与 CPU/内存速度差，存放 I/O 数据

口诀：

`Cache管CPU-主存，Buffer管I/O`

### 6. SPOOLing

SPOOLing = 假脱机技术  
作用：把独占设备改造成逻辑上的共享设备

关键词：

- 输入井 / 输出井
- 缓冲区
- 排队管理

### 7. 四张表

- SDT：系统设备表
- DCT：设备控制表
- COCT：控制器控制表
- CHCT：通道控制表

口诀：

`系设控通`

### 8. 磁盘调度

- FCFS：先来先服务
- SSTF：最短寻道时间优先
- SCAN：电梯算法
- C-SCAN：单向扫描

做题先看：

1. 初始磁头位置
2. 请求序列
3. 初始方向

口诀：

- `FCFS先来`
- `SSTF最近`
- `SCAN像电梯`

## 七、第6章 文件管理必背

### 1. 文件与文件系统

- 文件：具有名字的一组相关信息集合
- 文件系统：管理文件的机制

### 2. FCB

FCB = File Control Block = 文件控制块  
记录文件名、物理位置、属性、长度等信息。

一句话记忆：

`FCB记身份`

### 3. FAT

FAT = File Allocation Table = 文件分配表  
记录文件各磁盘块之间的链接关系。

一句话记忆：

`FAT记去路`

### 4. 文件目录

目录是一种数据结构，由若干目录项组成。  
作用：

- 按名存取
- 提高文件检索效率

### 5. 目录结构

- 单级目录：简单，但不允许重名
- 二级目录：主目录 + 用户目录
- 多级/树形目录：层次清晰，允许重名，现代系统常用

### 6. 文件物理结构

- 连续分配
- 链接分配
- 索引分配

特点：

- 连续分配：随机访问快，但不灵活，易产生外碎片
- 链接分配：扩展方便，但随机访问差
- 索引分配：随机访问好，但索引表占空间

### 7. 索引结构

一个索引块可存的地址项数：

```text
块大小 / 地址项大小
```

例如：

```text
1KB = 1024B
地址项4B
1024 / 4 = 256
```

则：

- 一级索引最多索引 256 个数据块
- 二级索引最多索引 256 × 256 个数据块

### 8. 位示图

位示图法：用一位表示一个磁盘块是否空闲。

口诀：

`一位管一块`

换算：

- 块号 -> 行列：用除法，商是行，余数是列
- 行列 -> 块号：`行 × 每行位数 + 列`

注意：

先看题目是从 0 开始还是从 1 开始编号。

## 八、全课程必会公式合集

### 1. 调度

```text
完成时间 = 进程结束运行的时刻
周转时间 = 完成时间 - 到达时间
带权周转时间 = 周转时间 / 服务时间
响应比 = (等待时间 + 服务时间) / 服务时间
```

### 2. 分页

```text
页号 = A / 页面大小
页内位移 = A % 页面大小
物理地址 = 块号 × 页面大小 + 位移
```

### 3. 分段

```text
物理地址 = 段基址 + 段内位移
```

### 4. 页面置换

```text
缺页率 = 缺页次数 / 访问总次数
```

### 5. 索引结构

```text
一个索引块可存地址项数 = 块大小 / 地址项大小
```

### 6. 位示图

```text
块号 -> 行列：除法
行列 -> 块号：行 × 每行位数 + 列
```

## 九、全课程高频易错点

### 第1章

- 并发不等于并行
- 用户态不是用户界面
- 通道不是普通 CPU

### 第2章

- 程序静态，进程动态
- 线程是调度单位，不是资源分配单位
- 阻塞不能直接到运行

### 第3章

- 同步不等于互斥
- 临界资源不等于临界区
- P/V 顺序别写反
- 不安全状态不等于死锁

### 第4章

- `1KB = 1024B`
- 分段题先判越界
- FIFO 与 LRU 容易混

### 第5章

- DMA 不等于通道
- Cache 不等于缓冲区
- 磁盘题一定先看方向

### 第6章

- FCB 不等于 FAT
- 索引块不是数据块
- 位示图题先看编号起点
