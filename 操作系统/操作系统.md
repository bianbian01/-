# 第一章 操作系统概述

## 1.1 操作系统定义

### 核心概念

* 操作系统是管理和控制计算机硬件与软件资源，合理组织计算机工作流程，并为用户和应用程序提供接口的一组系统软件。
* 操作系统处在硬件和用户程序之间，向下管理硬件资源，向上提供方便、统一、安全的使用环境。
* 操作系统的本质可以概括为：资源管理者、程序控制者、用户接口提供者。

> ⭐考试重点

### 考试高频考点

* 操作系统是系统软件。
* 操作系统管理处理器、存储器、设备、文件等资源。
* 操作系统为用户和应用程序提供接口。

### 常见简答题

* 什么是操作系统？
* 操作系统在计算机系统中的作用是什么？

### 常见计算题

* 本节通常不出计算题。

### 易错点

* 不要把操作系统只理解为“用户界面”，它更核心的作用是资源管理和控制程序执行。
* 不要把应用软件写成操作系统的一部分。

### 一句话速记

* 操作系统是管理软硬件资源、控制程序执行并提供接口的系统软件。

## 1.2 操作系统设计目标

### 核心概念

* 方便性：让用户更方便地使用计算机。
* 有效性：提高系统资源利用率和吞吐量。
* 可扩充性：便于增加新功能、适应新硬件和新需求。
* 可移植性：便于移植到不同硬件平台。
* 可靠性：保证系统长期稳定、正确运行。
* 开放性：遵循标准，便于互联、兼容和扩展。

> ⭐考试重点

### 考试高频考点

* 设计目标常作为填空题、选择题或简答题出现。
* 方便性和有效性是最基本的两个目标。

### 常见简答题

* 操作系统有哪些设计目标？
* 为什么操作系统要强调有效性和方便性？

### 常见计算题

* 本节通常不出计算题。

### 易错点

* “可扩充性”和“开放性”不是同一个概念：可扩充性强调自身功能扩展，开放性强调标准化和互联互通。

### 一句话速记

* 操作系统设计目标：方便、有效、可扩、可移、可靠、开放。

## 1.3 操作系统主要功能

### 核心概念

* 处理器管理：负责进程、线程、处理机调度、同步与通信。
* 存储器管理：负责内存分配、回收、地址转换、存储保护和虚拟存储。
* 设备管理：负责 I/O 控制、缓冲、设备分配、设备驱动和磁盘调度。
* 文件管理：负责文件组织、目录管理、文件存取、文件保护和外存空间管理。
* 用户接口：提供命令接口、程序接口、图形用户界面等。

> ⭐考试重点

### 考试高频考点

* 四大资源管理：处理器管理、存储器管理、设备管理、文件管理。
* 教师强调：主要功能里除了四大资源管理，还要记住“用户接口”。

### 常见简答题

* 操作系统的主要功能有哪些？
* 处理器管理、存储器管理、设备管理、文件管理分别负责什么？

### 常见计算题

* 本节本身通常不出计算题，但处理器管理、存储器管理、设备管理后续会出计算题。

### 易错点

* 不要漏写用户接口。
* 不要把“网络通信管理”作为本课程核心必背主线，考试更常围绕四大资源管理展开。

### 一句话速记

* 操作系统主要功能：管 CPU、管内存、管设备、管文件、给接口。

## 1.4 操作系统基本特征

### 核心概念

* 并发：多个程序在同一时间间隔内推进。
* 共享：系统资源可被多个并发程序共同使用。
* 虚拟：通过技术手段把一个物理实体变成多个逻辑实体，或把多个物理实体抽象为一个逻辑实体。
* 异步：进程推进速度不可预知，但系统必须保证运行结果正确。

> ⭐考试重点

### 考试高频考点

* 并发和共享是操作系统两个最基本特征。
* 虚拟包括处理器虚拟、存储器虚拟、设备虚拟等。
* 异步性是并发环境带来的重要特征。

### 常见简答题

* 操作系统的基本特征有哪些？
* 并发和并行有什么区别？
* 什么是虚拟？

### 常见计算题

* 本节通常不出计算题。

### 易错点

* 并发不等于并行。并发强调同一时间间隔内推进；并行强调同一时刻真正同时执行。
* 共享不是无条件同时使用，互斥共享资源一次只能一个进程访问。

### 一句话速记

* 操作系统四特征：并发、共享、虚拟、异步。

## 1.5 操作系统类型

### 核心概念

* 批处理系统：用户把作业成批提交，系统自动顺序处理，吞吐量较高但交互性差。
* 分时系统：多个用户通过终端共享主机，系统按时间片轮流服务，交互性强。
* 实时系统：要求在规定时间内完成响应，分为硬实时和软实时。
* 分布式操作系统：管理多台计算机上的资源，使其协同工作。
* 嵌入式操作系统：面向特定设备和应用场景，常强调实时性、可靠性和资源受限。
* 微机操作系统：面向个人计算机，了解即可。

> ⭐考试重点

### 考试高频考点

* 教师强调重点看批处理系统、分时系统、实时系统。
* 分布式和嵌入式知道大概功能即可。

### 常见简答题

* 批处理系统、分时系统、实时系统各有什么特点？
* 硬实时系统和软实时系统有什么区别？

### 常见计算题

* 本节通常不出计算题。

### 易错点

* 分时系统的核心是时间片轮转和交互性。
* 实时系统的核心不是“速度快”，而是“在规定时间内响应”。

### 一句话速记

* 批处理重吞吐，分时重交互，实时重期限。

## 1.6 用户态与内核态

### 核心概念

* 用户态：普通用户程序运行的状态，只能执行非特权指令，不能直接操作关键系统资源。
* 内核态：操作系统内核运行的状态，可以执行特权指令，可以访问和管理系统资源。
* 两种状态的划分是实现系统保护的重要基础。
* 常见从用户态进入内核态的原因包括：系统调用、中断、异常。

> ⭐考试重点

### 考试高频考点

* 为什么要划分用户态和内核态。
* 什么是特权指令、非特权指令。
* 用户态到内核态的典型切换原因。

### 常见简答题

* 为什么要划分用户态和内核态？
* 用户态和内核态有什么区别？

### 常见计算题

* 本节通常不出计算题。

### 易错点

* 划分用户态和内核态的首要关键词是安全性、可靠性、保护系统资源。
* 不要把“提高性能”作为主要原因。

### 一句话速记

* 用户态和内核态的划分，是为了安全可靠地保护系统资源。

## 1.7 PSW、特权指令与中断

### 核心概念

* PSW：Program Status Word，程序状态字，用来保存程序运行状态、条件码、中断状态、CPU 状态等信息。
* 特权指令：只能在内核态执行的指令，如 I/O 指令、修改中断屏蔽字、设置系统状态等。
* 非特权指令：用户态也能执行的普通运算、访存、数据传送等指令。
* 中断：CPU 暂停当前程序，转去处理突发事件，处理完后恢复原程序继续执行。
* 通道：专门处理 I/O 设备数据传输的处理器，一般没有独立内存，需要使用主存。

> ⭐考试重点

### 考试高频考点

* 多道程序设计实现的硬件基础：中断和通道。
* 中断处理三步：保护现场、处理中断、恢复现场。
* PSW 名词解释。

### 常见简答题

* 什么是 PSW？
* 什么是通道？
* 中断处理过程包括哪几步？

### 常见计算题

* 本节通常不出计算题。

### 易错点

* 通道不是普通线路，而是专门管理 I/O 传输的处理器。
* 中断处理步骤写三步即可，不必写得过细。

### 一句话速记

* 多道程序靠中断和通道，中断三步是保护现场、处理中断、恢复现场。

# 第二章 进程管理

## 2.1 程序执行与进程引入

### 核心概念

* 程序顺序执行的特点：顺序性、封闭性、可再现性。
* 并发执行的特点：间断性、失去封闭性、不可再现性。
* 并发执行使多个程序在同一时间间隔内交替推进，提高系统资源利用率，但也带来同步、互斥、死锁等问题。

> ⭐考试重点

### 考试高频考点

* 顺序执行三特点。
* 并发执行的概念。
* 并发与并行的区别。

### 常见简答题

* 程序顺序执行有哪些特点？
* 程序并发执行会带来哪些变化？

### 常见计算题

* 本节通常不出计算题。

### 易错点

* 原笔记中把“程序执行的三个特点”写成并发性、独立性、异步性不准确；这是进程或并发环境相关特征，不是顺序执行三特点。

### 一句话速记

* 顺序执行：顺序、封闭、可再现；并发执行：间断、失封闭、不可再现。

## 2.2 进程定义与 PCB

### 核心概念

* 进程是具有独立功能、可并发执行的程序关于某个数据集合的一次执行过程。
* 进程是操作系统进行资源分配和保护的基本单位。
* PCB：Process Control Block，进程控制块，是进程存在的唯一标志。
* PCB 中通常包括进程标识、进程状态、程序计数器、寄存器现场、调度信息、资源清单等。
* 进程实体由程序段、数据段和 PCB 构成。

```text
进程实体 = 程序段 + 数据段 + PCB
```

> ⭐考试重点

### 考试高频考点

* 进程定义。
* PCB 的作用。
* 进程实体组成。

### 常见简答题

* 什么是进程？
* PCB 是什么？为什么说 PCB 是进程存在的唯一标志？
* 进程实体由哪几部分组成？

### 常见计算题

* 本节通常不出计算题。

### 易错点

* 程序是静态的，进程是动态的执行过程。
* 进程不是单纯的程序文件，必须包含运行状态和控制信息。

### 一句话速记

* 进程是程序的一次执行过程，PCB 是进程存在的唯一标志。

## 2.3 进程特征与状态转换

### 核心概念

* 进程特征：动态性、并发性、独立性、异步性、结构性。
* 三态模型：就绪态、运行态、阻塞态。
* 五态模型：创建态、就绪态、运行态、阻塞态、终止态。
* 带挂起状态模型：在就绪、阻塞等状态基础上增加挂起，用于实现内外存交换。

进程三态常见转换：

1. 就绪态 -> 运行态：进程被调度，获得 CPU。
2. 运行态 -> 就绪态：时间片用完，或被高优先级进程抢占。
3. 运行态 -> 阻塞态：请求 I/O 或等待某事件。
4. 阻塞态 -> 就绪态：等待事件完成。

> ⭐考试重点

### 考试高频考点

* 进程五个特征。
* 三态、五态模型。
* 为什么运行态不能直接从阻塞态恢复为运行态。
* 挂起与内外存交换的关系。

### 常见简答题

* 进程有哪些特征？
* 画出进程三态模型并说明转换原因。
* 挂起和激活的作用是什么？

### 常见计算题

* 本节通常不出计算题，但进程状态判断可出选择题。

### 易错点

* 阻塞态等待事件完成后通常先进入就绪态，而不是直接进入运行态。
* 运行态到阻塞态是进程主动等待事件；阻塞态到就绪态是事件完成。

### 一句话速记

* 三态转换：就绪等 CPU，运行占 CPU，阻塞等事件。

## 2.4 原语、作业与三级调度

### 核心概念

* 原语是由若干条指令组成、用于完成特定系统功能的一段程序，执行时不可中断。
* 原子性表示操作要么不执行，要么一次完整执行，中间不能被打断。
* 作业是用户提交给操作系统完成的一项任务，通常包括程序、数据、作业说明书。
* 高级调度又称作业调度，从外存后备队列中选择作业进入内存。
* 中级调度又称内存调度，负责进程挂起与激活，实现内外存交换。
* 低级调度又称进程调度，从就绪队列中选择进程分配 CPU，发生最频繁。

> ⭐考试重点

### 考试高频考点

* 原语和原子性。
* 作业三部分组成。
* CPU 三级调度的名称和作用。

### 常见简答题

* 什么是原语？什么是原子性？
* 作业由哪几部分组成？
* 高级调度、中级调度、低级调度分别完成什么工作？

### 常见计算题

* 本节通常不单独出计算题。

### 易错点

* 中级调度不是“选择阻塞队列进入就绪队列”，它的核心是挂起、激活和内外存交换。
* 低级调度最频繁。

### 一句话速记

* 高级管作业进内存，中级管换入换出，低级管谁占 CPU。

## 2.5 进程调度方式与调度算法

### 核心概念

* 非抢占式调度：当前进程主动放弃 CPU 或完成前，系统不强行剥夺 CPU。
* 抢占式调度：系统可因时间片到、高优先级进程到达等原因剥夺当前进程的 CPU。
* FCFS：先来先服务，按到达顺序执行，简单但可能产生长作业拖累短作业的“护航效应”。
* SJF/SPF：短作业或短进程优先，可降低平均等待时间，但可能导致长作业饥饿。
* HRRN：高响应比优先，兼顾等待时间和服务时间。
* RR：时间片轮转，适合分时系统，时间片大小影响响应和开销。
* 优先级调度：按优先级选择进程，低优先级进程可能饥饿。

```text
响应比 = (等待时间 + 服务时间) / 服务时间
```

常用公式：

```text
完成时间 = 进程完成运行的时刻
周转时间 = 完成时间 - 到达时间
带权周转时间 = 周转时间 / 服务时间
平均周转时间 = 各进程周转时间之和 / 进程数
平均带权周转时间 = 各进程带权周转时间之和 / 进程数
```

> ⭐考试重点

### 考试高频考点

* FCFS、SJF、HRRN、RR 调度顺序。
* 周转时间、带权周转时间计算。
* 甘特图。

### 常见简答题

* 抢占式调度和非抢占式调度有什么区别？
* 时间片轮转算法有什么特点？
* 短作业优先算法有什么优缺点？

### 常见计算题

调度题通用流程：

1. 按题目指定算法确定调度顺序。
2. 画甘特图。
3. 求每个进程完成时间。
4. 求周转时间和带权周转时间。
5. 求平均周转时间和平均带权周转时间。

### 易错点

* FCFS 一般说“护航效应”，不要硬写成典型饥饿算法。
* HRRN 的等待时间会随时间变化，每次调度时都要重新计算。
* RR 时间片过大近似 FCFS，过小会导致上下文切换开销大。

### 一句话速记

* 调度题先画甘特图，再算完成、周转、带权周转。

## 2.6 线程

### 核心概念

* 线程是进程内一个相对独立的执行流。
* 线程是 CPU 调度的基本单位。
* 进程是资源分配的基本单位。
* 同一进程内的线程共享该进程的地址空间、打开文件等资源，但每个线程有自己的程序计数器、寄存器和栈。

> ⭐考试重点

### 考试高频考点

* 线程的定义。
* 线程与进程的区别。
* 引入线程的目的。

### 常见简答题

* 什么是线程？
* 进程和线程有什么区别？
* 为什么要引入线程？

### 常见计算题

* 本节通常不出计算题。

### 易错点

* 线程共享进程资源，但线程并不是没有独立上下文。
* 进程和线程不能都笼统写成“资源分配基本单位”。

### 一句话速记

* 进程管资源，线程管执行。

# 第三章 进程同步、互斥与死锁

## 3.1 同步、互斥、临界资源与临界区

### 核心概念

* 同步：多个进程因执行顺序或协作关系而相互等待、相互制约。
* 互斥：多个进程不能同时访问同一个临界资源。
* 临界资源：一次只允许一个进程访问的资源。
* 临界区：访问临界资源的代码段。

临界区访问原则：

* 空闲让进
* 忙则等待
* 有限等待
* 让权等待

> ⭐考试重点

### 考试高频考点

* 同步与互斥的区别。
* 临界资源与临界区定义。
* 临界区访问四原则。

### 常见简答题

* 什么是同步？什么是互斥？
* 什么是临界资源和临界区？
* 临界区访问应遵循哪些原则？

### 常见计算题

* 本节通常与 PV 设计题结合出现。

### 易错点

* 同步强调先后关系，互斥强调不能同时访问。
* 临界区是代码段，不是资源本身。

### 一句话速记

* 同步管顺序，互斥管独占。

## 3.2 信号量与 PV 操作

### 核心概念

* 信号量是用于实现同步与互斥的整型变量，只能通过 P、V 原语操作。
* P 操作表示申请资源或等待条件。
* V 操作表示释放资源或通知条件满足。

```text
P(S):
  S = S - 1
  若 S < 0，则当前进程阻塞

V(S):
  S = S + 1
  若 S <= 0，则唤醒一个等待进程
```

常见信号量初值：

* 互斥信号量 `mutex = 1`
* 空缓冲区数量 `empty = n`
* 满缓冲区数量 `full = 0`
* 前驱关系信号量 `s = 0`

> ⭐考试重点

### 考试高频考点

* P/V 操作含义。
* 信号量初值。
* 用信号量写同步与互斥伪代码。

### 常见简答题

* 什么是信号量？
* P 操作和 V 操作分别表示什么？

### 常见计算题

PV 设计题流程：

1. 找临界资源，设置互斥信号量。
2. 找同步先后关系，设置同步信号量。
3. 确定每个信号量初值。
4. 在访问资源前 P，访问后 V。
5. 检查是否会死锁或违反同步顺序。

### 易错点

* 信号量初值最关键。
* P/V 顺序不能乱，尤其是生产者消费者中 `empty/full` 和 `mutex` 的位置。
* 互斥信号量初值通常为 1，同步信号量初值常为 0。

### 一句话速记

* P 是申请或等待，V 是释放或通知。

## 3.3 生产者消费者问题

### 核心概念

* 生产者向缓冲区放入产品，消费者从缓冲区取出产品。
* 缓冲区是临界资源，访问缓冲区必须互斥。
* 生产者不能在缓冲区满时继续放入。
* 消费者不能在缓冲区空时继续取出。

标准信号量：

```text
semaphore mutex = 1;  // 缓冲区互斥
semaphore empty = n;  // 空缓冲区数量
semaphore full = 0;   // 满缓冲区数量
```

标准伪代码：

```text
producer:
  while true:
    生产产品
    P(empty)
    P(mutex)
    放入缓冲区
    V(mutex)
    V(full)

consumer:
  while true:
    P(full)
    P(mutex)
    取出产品
    V(mutex)
    V(empty)
    消费产品
```

> ⭐考试重点

### 考试高频考点

* `mutex`、`empty`、`full` 的含义和初值。
* P/V 操作顺序。
* 同步关系和互斥关系同时存在。

### 常见简答题

* 生产者消费者问题中有哪些同步和互斥关系？
* 为什么需要 `empty` 和 `full` 两个同步信号量？

### 常见计算题

* 给出缓冲区大小，写生产者消费者 PV 伪代码。
* 判断给定 PV 代码是否可能死锁。

### 易错点

* 生产者应先 P(empty)，再进入临界区。
* 消费者应先 P(full)，再进入临界区。
* 不要在临界区内执行耗时的“生产”和“消费”动作。

### 一句话速记

* 生产者先找空位，消费者先找产品，进缓冲区前都要互斥。

## 3.4 读者写者问题

### 核心概念

* 多个读者可以同时读。
* 写者与写者互斥。
* 读者与写者互斥。
* 常见模型包括读者优先、写者优先、公平读写。

读者优先基本思想：

```text
semaphore rw = 1;      // 控制读写互斥
semaphore mutex = 1;   // 控制 readcount 互斥
int readcount = 0;

reader:
  P(mutex)
  readcount++
  if readcount == 1:
    P(rw)
  V(mutex)

  读文件

  P(mutex)
  readcount--
  if readcount == 0:
    V(rw)
  V(mutex)

writer:
  P(rw)
  写文件
  V(rw)
```

> ⭐考试重点

### 考试高频考点

* 读读共享。
* 读写互斥。
* 写写互斥。
* 第一个读者加锁，最后一个读者解锁。

### 常见简答题

* 读者写者问题中的互斥关系有哪些？
* 为什么需要 `readcount`？

### 常见计算题

* 写读者优先的 PV 伪代码。
* 判断读者写者代码是否会导致写者饥饿。

### 易错点

* `readcount` 本身也是共享变量，修改它必须互斥。
* 读者优先可能导致写者饥饿。

### 一句话速记

* 读读可共享，读写和写写都互斥。

## 3.5 哲学家进餐问题

### 核心概念

* 哲学家进餐问题用于说明并发进程竞争多个临界资源时可能发生死锁。
* 每个哲学家需要同时拿到左右两支筷子才能进餐。
* 若所有哲学家都先拿左筷子再等待右筷子，可能形成循环等待。

常见解决方法：

* 最多允许 4 个哲学家同时拿筷子。
* 奇数号和偶数号哲学家拿筷子顺序相反。
* 同时申请左右两支筷子。

示例：

```text
semaphore room = 4;
semaphore chopstick[5] = {1,1,1,1,1};

philosopher i:
  while true:
    思考
    P(room)
    P(chopstick[i])
    P(chopstick[(i+1) % 5])
    进餐
    V(chopstick[(i+1) % 5])
    V(chopstick[i])
    V(room)
```

> ⭐考试重点

### 考试高频考点

* 死锁产生原因。
* 如何破坏循环等待。
* 如何限制同时竞争资源的进程数。

### 常见简答题

* 哲学家进餐问题为什么可能死锁？
* 如何避免哲学家进餐问题中的死锁？

### 常见计算题

* 写避免死锁的哲学家进餐 PV 伪代码。

### 易错点

* 每支筷子是一个互斥资源。
* 只给每支筷子设置互斥信号量，不一定能避免死锁。

### 一句话速记

* 哲学家进餐的核心是破坏“每人拿一支再等一支”的循环等待。

## 3.6 死锁

### 核心概念

* 死锁是指多个进程因竞争资源而相互等待，若无外力作用都不能继续推进。
* 死锁产生的四个必要条件：互斥、不剥夺、请求并保持、循环等待。
* 资源分为可抢占资源和不可抢占资源。

死锁处理方法：

* 预防死锁：破坏死锁必要条件之一。
* 避免死锁：动态判断资源分配后是否仍处于安全状态。
* 检测死锁：允许死锁发生，之后检测。
* 解除死锁：剥夺资源、撤销进程或进程回退。

> ⭐考试重点

### 考试高频考点

* 死锁定义。
* 死锁四个必要条件。
* 死锁预防、避免、检测、解除的区别。

### 常见简答题

* 什么是死锁？
* 死锁产生的必要条件有哪些？
* 死锁有哪些处理方法？

### 常见计算题

* 判断资源分配图是否存在死锁。
* 用银行家算法判断系统是否安全。

### 易错点

* 四个必要条件必须同时满足才可能发生死锁。
* 不安全状态不一定已经死锁，但可能导致死锁。

### 一句话速记

* 死锁四条件：互斥、不剥夺、请求保持、循环等待。

## 3.7 银行家算法与资源分配图

### 核心概念

* 安全状态：系统存在一个安全序列，使所有进程都能顺利完成。
* 银行家算法通过试分配和安全性检查，避免系统进入不安全状态。
* 资源分配图中，圆圈表示进程，方框表示资源类，方框内小点表示资源实例。
* 请求边：进程 -> 资源。
* 分配边：资源实例 -> 进程。

银行家算法数据结构：

```text
Available：系统当前可用资源
Max：每个进程最大资源需求
Allocation：每个进程已分配资源
Need：每个进程尚需资源
Need = Max - Allocation
```

银行家算法判断流程：

1. 判断 `Request <= Need`，否则请求非法。
2. 判断 `Request <= Available`，否则资源不足，进程等待。
3. 试分配资源。
4. 执行安全性算法，寻找安全序列。
5. 若存在安全序列，则真正分配；否则撤销试分配。

安全性算法流程：

1. 令 `Work = Available`。
2. 对每个进程设置 `Finish = false`。
3. 寻找满足 `Finish == false` 且 `Need <= Work` 的进程。
4. 找到后令 `Work = Work + Allocation`，并设置 `Finish = true`。
5. 若所有进程 `Finish == true`，系统安全；否则不安全。

> ⭐考试重点

### 考试高频考点

* `Need = Max - Allocation`。
* 安全状态和安全序列。
* 资源分配图符号含义。

### 常见简答题

* 什么是安全状态？
* 银行家算法的基本思想是什么？
* 资源分配图中圆圈、方框、小点、箭头分别表示什么？

### 常见计算题

* 根据 Available、Max、Allocation 求 Need。
* 判断某次请求能否被满足。
* 找安全序列。

### 易错点

* `Request <= Available` 只能说明当前资源够，不代表分配后一定安全。
* 找安全序列时，进程完成后要释放它已占有的 Allocation。

### 一句话速记

* 银行家算法先试分配，再找安全序列。

# 第四章 存储管理

## 4.1 地址、重定位与连续分配

### 核心概念

* 逻辑地址：程序中使用的地址，又称相对地址、虚地址。
* 物理地址：内存中的实际地址，又称绝对地址、实地址。
* 重定位：把逻辑地址转换为物理地址。
* 静态重定位：程序装入内存时一次性完成地址转换，运行期间不能移动。
* 动态重定位：程序运行时由硬件地址变换机构完成地址转换，运行期间可以移动。

连续分配方式：

* 单一连续分配：一次只装入一道用户程序。
* 固定分区分配：分区大小固定，容易产生内部碎片。
* 可变分区分配：按作业大小动态划分，容易产生外部碎片。

可变分区算法：

* FF：首次适应。
* NF：循环首次适应。
* BF：最佳适应。
* WF：最坏适应。

> ⭐考试重点

### 考试高频考点

* 逻辑地址和物理地址。
* 静态重定位和动态重定位。
* 固定分区、可变分区、内部碎片、外部碎片。
* 首次适应、最佳适应、最坏适应。

### 常见简答题

* 什么是逻辑地址和物理地址？
* 静态重定位和动态重定位有什么区别？
* 固定分区和可变分区有什么区别？

### 常见计算题

* 根据空闲分区表，按 FF、BF、WF 分配作业。
* 判断分配后剩余空闲区大小。

### 易错点

* 固定分区主要产生内部碎片。
* 可变分区主要产生外部碎片。
* “最佳适应”和“最坏适应”只是策略名称，不代表绝对最好或最差。

### 一句话速记

* 逻辑地址经重定位变物理地址，固定分区内碎片，可变分区外碎片。

## 4.2 覆盖与交换

### 核心概念

* 覆盖：把程序划分为若干功能段，必要时调入覆盖区，用小内存运行大程序。
* 交换：把暂时不用的进程从内存换出到外存，需要时再换入内存。
* 覆盖主要在同一程序内部安排不同程序段共用内存区域。
* 交换通常以进程为单位，在内存和外存之间移动。

> ⭐考试重点

### 考试高频考点

* 覆盖与交换的概念和区别。
* 交换与中级调度、挂起状态的联系。

### 常见简答题

* 什么是覆盖？
* 什么是交换？
* 覆盖和交换有什么区别？

### 常见计算题

* 本节通常不出复杂计算题。

### 易错点

* 覆盖不是把整个进程换出。
* 交换常与挂起、激活和中级调度联系。

### 一句话速记

* 覆盖是程序段共用内存，交换是进程内外存换入换出。

## 4.3 分页存储管理

### 核心概念

* 分页把逻辑地址空间划分为大小相等的页。
* 把物理内存划分为大小相等的块或页框。
* 页大小等于块大小。
* 页表记录页号到物理块号的映射关系。
* 分页无外部碎片，但可能有页内碎片。

地址结构：

```text
逻辑地址 = 页号 P + 页内偏移 W
物理地址 = 块号 F + 页内偏移 W
```

地址转换公式：

```text
物理地址 = 块号 F * 页面大小 + 页内偏移 W
```

若页面大小为 `2^k`：

* 低 `k` 位为页内偏移。
* 其余高位为页号。

分页地址转换流程：

1. 根据页面大小拆分页号 P 和页内偏移 W。
2. 判断页号是否越界。
3. 查页表得到物理块号 F。
4. 计算物理地址。

> ⭐考试重点

### 考试高频考点

* 页、块、页表、页内偏移。
* 分页地址结构。
* 根据页表计算物理地址。
* 判断页号越界。

### 常见简答题

* 什么是分页存储管理？
* 分页存储管理有什么优缺点？
* 页表的作用是什么？

### 常见计算题

* 已知页面大小和逻辑地址，求页号和页内偏移。
* 已知页表，求物理地址。
* 判断是否越界或缺页。

### 易错点

* 页号是否越界要先判断。
* 页内偏移不能超过页面大小。
* 二进制地址拆分时低位是页内偏移，高位是页号。

### 一句话速记

* 分页地址转换：拆页号和偏移，查页表得块号，再算物理地址。

## 4.4 快表、多级页表与倒置页表

### 核心概念

* 快表 TLB，又称联想存储器，用来缓存页表项，提高地址转换速度。
* 快表命中时可以直接得到物理块号。
* 快表未命中时需要访问内存中的页表。
* 多级页表用于减少页表连续占用内存的压力，并扩大可管理地址空间。
* 倒置页表按物理块建立表项，是“反过来”的页表结构。

有效访问时间常见形式：

```text
有效访问时间 = 命中率 * 命中访问时间 + 未命中率 * 未命中访问时间
```

> ⭐考试重点

### 考试高频考点

* 快表的作用。
* 多级页表的目的。
* 倒置页表概念。

### 常见简答题

* 什么是快表？它有什么作用？
* 为什么要引入多级页表？
* 什么是倒置页表？

### 常见计算题

* 给定快表命中率，计算有效访问时间。

### 易错点

* 多级页表不是为了减少访问次数，而是为了减少页表连续占用内存的压力。
* 快表可以提高访问速度，但未命中时仍需访问页表。

### 一句话速记

* 快表提速，多级页表省连续空间，倒置页表按物理块反查。

## 4.5 分段存储管理

### 核心概念

* 分段按程序的逻辑结构划分，如主程序段、子程序段、数据段、栈段等。
* 段长不固定。
* 段表记录段基址和段长。

地址结构：

```text
逻辑地址 = 段号 S + 段内地址 W
```

地址转换流程：

1. 判断段号 S 是否越界。
2. 查段表得到段基址和段长。
3. 判断段内地址 W 是否小于段长。
4. 计算物理地址。

```text
物理地址 = 段基址 + 段内地址
```

> ⭐考试重点

### 考试高频考点

* 段号、段内地址、段表。
* 段基址和段长。
* 段内地址越界判断。

### 常见简答题

* 什么是分段存储管理？
* 分段存储管理有什么特点？
* 分段和分页有什么区别？

### 常见计算题

* 根据段表判断逻辑地址是否合法。
* 根据段基址和段内地址计算物理地址。

### 易错点

* 段内地址必须小于段长，若 `W >= 段长` 则越界。
* 分段地址空间是二维的，分页地址空间通常视为一维。

### 一句话速记

* 分段先查段长防越界，再用段基址加段内地址。

## 4.6 分页与分段比较、段页式存储管理

### 核心概念

分页与分段区别：

* 页是信息的物理单位，段是信息的逻辑单位。
* 页大小固定，段长度不固定。
* 分页主要为了系统内存管理，分段更符合用户程序逻辑。
* 分页地址空间是一维，分段地址空间是二维。

段页式：

* 先分段，段内再分页。
* 既保留分段的逻辑性，又利用分页方便内存管理。

段页式地址结构：

```text
逻辑地址 = 段号 S + 段内页号 P + 页内偏移 W
```

段页式地址转换流程：

1. 用段号查段表，得到该段页表起始地址和页表长度。
2. 判断段内页号是否越界。
3. 用段内页号查页表，得到物理块号。
4. 计算物理地址。

```text
物理地址 = 块号 * 页大小 + 页内偏移
```

> ⭐考试重点

### 考试高频考点

* 分页与分段区别。
* 段页式地址结构。
* 段表和页表的查找顺序。

### 常见简答题

* 分页和分段有什么区别？
* 什么是段页式存储管理？

### 常见计算题

* 根据段表、页表进行段页式地址转换。
* 判断段号、段内页号是否越界。

### 易错点

* 段页式是先分段，再对每段分页。
* 段页式要先查段表，再查页表。

### 一句话速记

* 段页式：先按逻辑分段，再按物理分页。

## 4.7 虚拟存储器与页面置换算法

### 核心概念

* 虚拟存储器把内存和外存结合起来，使用户感觉有比实际内存更大的存储空间。
* 虚拟存储器建立在局部性原理基础上。
* 时间局部性：刚访问过的数据近期可能再次访问。
* 空间局部性：刚访问位置附近的数据近期可能被访问。
* 请求分页：页面需要时才调入内存。
* 缺页中断：访问页不在内存时产生的中断。

缺页处理流程：

1. 访问页表发现页不在内存。
2. 产生缺页中断。
3. 操作系统查找该页在外存中的位置。
4. 若内存有空闲块，则调入该页。
5. 若无空闲块，则按页面置换算法淘汰某页。
6. 修改页表，重新执行被中断的指令。

页面置换算法：

* FIFO：淘汰最早进入内存的页。
* OPT：淘汰未来最长时间不会访问的页，理论最优，实际不可实现。
* LRU：淘汰最近最长时间未使用的页，用过去推测未来。
* CLOCK：近似 LRU，了解即可。

缺页率：

```text
缺页率 = 缺页次数 / 页面访问总次数
```

> ⭐考试重点

### 考试高频考点

* 虚拟存储器定义。
* 局部性原理。
* 缺页中断处理流程。
* FIFO、OPT、LRU 页面置换。
* 缺页次数和缺页率。

### 常见简答题

* 什么是虚拟存储器？
* 什么是局部性原理？
* FIFO、OPT、LRU 分别如何选择淘汰页面？

### 常见计算题

页面置换题流程：

1. 写出页面访问串和页框数。
2. 按算法逐个访问页面。
3. 命中则不计缺页。
4. 未命中则缺页次数加 1。
5. 内存满时按算法置换页面。
6. 统计缺页次数和缺页率。

### 易错点

* FIFO 可能出现 Belady 异常。
* OPT 看未来，LRU 看过去。
* 缺页次数包括最初装入空页框时的缺页。

### 一句话速记

* FIFO 淘汰最早进来的，OPT 淘汰未来最晚用的，LRU 淘汰过去最久没用的。

# 第五章 I/O管理与设备管理

## 5.1 I/O设备分类与控制方式

### 核心概念

按信息传输单位分类：

* 字符设备：以字符为单位传输，如键盘、打印机。
* 块设备：以数据块为单位传输，如磁盘。

按资源分配方式分类：

* 独占设备
* 共享设备
* 虚拟设备

I/O 控制方式：

* 程序直接控制方式：CPU 不断查询设备状态，效率低。
* 中断控制方式：设备完成后发中断通知 CPU。
* DMA 方式：设备和内存之间直接传输数据，CPU 只参与初始化和结束处理。
* 通道方式：由通道专门管理 I/O 操作，进一步减轻 CPU 负担。

> ⭐考试重点

### 考试高频考点

* 字符设备和块设备。
* 独占、共享、虚拟设备。
* 四种 I/O 控制方式对比。
* DMA 与通道。

### 常见简答题

* I/O 设备有哪些分类方式？
* 四种 I/O 控制方式分别是什么？
* DMA 方式有什么特点？

### 常见计算题

* 本节通常不出复杂计算题。

### 易错点

* DMA 不是完全不需要 CPU，CPU 仍需参与初始化和结束处理。
* 通道是处理 I/O 的专用处理器，不同于普通 CPU。

### 一句话速记

* I/O 控制从 CPU 全程盯着，逐步发展到中断、DMA、通道分担。

## 5.2 缓冲、SPOOLing与设备分配

### 核心概念

* 缓冲用于缓和 CPU 与 I/O 设备速度不匹配，减少中断次数，提高并行性。
* Cache 主要缓解 CPU 与主存速度差，保存主存副本。
* 缓冲区主要缓解设备与 CPU/内存速度差，保存 I/O 数据。
* SPOOLing 是假脱机技术，把独占设备改造成逻辑上的共享设备。
* 打印机假脱机是 SPOOLing 的典型例子。

SPOOLing 组成：

* 输入井
* 输出井
* 输入进程
* 输出进程
* 输入缓冲区
* 输出缓冲区

设备分配四张表：

* SDT：系统设备表
* DCT：设备控制表
* COCT：控制器控制表
* CHCT：通道控制表

> ⭐考试重点

### 考试高频考点

* Cache 与缓冲区区别。
* SPOOLing 概念和作用。
* 设备分配四张表。

### 常见简答题

* 什么是 SPOOLing？
* Cache 和缓冲区有什么区别？
* 设备分配涉及哪些数据结构？

### 常见计算题

* 本节通常不出复杂计算题。

### 易错点

* SPOOLing 的本质是将独占设备虚拟成共享设备。
* Cache 和缓冲区存放的数据和目的都不同。

### 一句话速记

* SPOOLing 就是假脱机，把独占设备逻辑共享。

## 5.3 磁盘结构与磁盘调度算法

### 核心概念

* 磁盘地址通常由柱面号、磁头号、扇区号组成。
* 磁盘访问时间由寻道时间、旋转延迟时间、传输时间组成。

```text
磁盘访问时间 = 寻道时间 + 旋转延迟时间 + 传输时间
```

常见磁盘调度算法：

* FCFS：按请求到达顺序服务。
* SSTF：优先服务距离当前磁头最近的请求。
* SCAN：电梯算法，磁头按一个方向移动并服务沿途请求，到端点后反向。
* C-SCAN：循环扫描，磁头只按一个方向服务，到端点后快速返回另一端继续。
* LOOK：类似 SCAN，但不一定走到磁盘端点，只到最远请求处返回。
* C-LOOK：类似 C-SCAN，只在请求范围内循环。

> ⭐考试重点

### 考试高频考点

* 磁盘访问时间公式。
* FCFS、SSTF、SCAN、C-SCAN。
* 计算磁头移动总道数。

### 常见简答题

* 磁盘访问时间由哪几部分组成？
* SCAN 和 C-SCAN 有什么区别？
* SSTF 有什么优缺点？

### 常见计算题

磁盘调度题流程：

1. 标出初始磁头位置。
2. 明确磁头移动方向。
3. 按指定算法写出访问顺序。
4. 逐段计算磁道移动距离。
5. 求总移动道数。

### 易错点

* SCAN 是否走到端点要按题意；若题目采用 LOOK 思路，则只到最远请求。
* C-SCAN 返回过程是否计入移动距离也要按题目要求。
* SSTF 每次都要从当前位置重新找最近请求。

### 一句话速记

* 磁盘调度题的关键是访问顺序，顺序错了全题都错。

## 6.2 VFS、FCB、FAT与目录

### 核心概念

* VFS：Virtual File System，虚拟文件系统，提供统一文件系统接口和数据结构。
* VFS 能连接不同文件系统，是因为它定义了各种文件系统都支持的统一接口和数据结构。
* VFS 严格意义上不是磁盘上固定存在的实体，主要存在于内存中。
* FCB：File Control Block，文件控制块，保存文件名、物理位置、属性等信息。
* FAT：File Allocation Table，文件分配表，用于记录文件各磁盘块之间的链接关系。
* JCB：Job Control Block，作业控制块。
* PCB：Process Control Block，进程控制块。
* 目录是一种数据结构，用于文件检索和按名存取。

目录作用：

* 实现按名存取。
* 提高文件检索速度。
* 支持文件共享。
* 支持文件重名控制。

目录结构：

* 单级目录
* 二级目录
* 多级目录或树形目录

> ⭐考试重点

### 考试高频考点

* VFS 概念。
* FCB、FAT、JCB、PCB 缩写区分。
* 目录作用和目录结构。

### 常见简答题

* 什么是 VFS？
* FCB 和 FAT 分别是什么？
* 文件目录有什么作用？

### 常见计算题

* 本节通常不直接出计算题，但 FAT 可与文件物理结构结合考查。

### 易错点

* PCB 对应进程，JCB 对应作业，FCB 对应文件，FAT 对应文件分配表。
* VFS 不是某一种具体磁盘文件系统。

### 一句话速记

* VFS 统一接口，FCB 管文件，FAT 管块链，目录管检索。

## 6.3 文件逻辑结构与物理结构

### 核心概念

* 文件逻辑结构是用户角度看到的文件组织方式。
* 文件物理结构是文件在外存上的实际存放方式。

常见物理结构：

* 连续结构：访问速度快，但容易产生外部碎片，不利于文件动态增长。
* 链接结构：便于文件增长，无外部碎片，但随机访问性能差。
* 索引结构：通过索引表记录文件块地址，支持随机访问，但索引表占用空间。

链接结构：

* 隐式链接：每个磁盘块中保存下一块指针。
* 显式链接：把链接指针集中放入 FAT 表。

> ⭐考试重点

### 考试高频考点

* 文件逻辑结构和物理结构。
* 连续、链接、索引三种物理结构优缺点。
* FAT 与显式链接。

### 常见简答题

* 文件逻辑结构和物理结构有什么区别？
* 连续结构、链接结构、索引结构各有什么优缺点？

### 常见计算题

* 根据索引项大小和磁盘块大小计算文件最大长度。

### 易错点

* 连续结构随机访问快，但扩展困难。
* 链接结构便于扩展，但随机访问差。
* 索引结构支持随机访问，但索引表需要额外空间。

### 一句话速记

* 连续快但难长，链接好长但难随机，索引能随机但费表。

## 6.4 文件存储空间管理与位示图

位示图：

```text
若每行有 n 位，块号从 0 开始：
行号 = 块号 / n
列号 = 块号 % n

若行列从 1 开始：
行号 = 块号 / n + 1
列号 = 块号 % n + 1
```

* 起始编号从 0 还是从 1。

## 6.5 索引结构计算

### 核心概念

* 索引结构通过索引表记录文件数据块地址。
* 直接索引项直接指向数据块。
* 一级间接索引项指向一个索引块，索引块中的每项再指向数据块。
* 二级间接索引项指向一级索引块，一级索引块再指向二级索引块，二级索引块再指向数据块。

索引结构计算核心：

```text
一个索引块可存索引项数 = 磁盘块大小 / 每个索引项大小
```

计算流程：

1. 明确磁盘块大小。
2. 明确索引项大小。
3. 计算一个索引块能存多少个索引项。
4. 计算直接索引可寻址大小。
5. 计算一级间接索引可寻址大小。
6. 计算二级间接索引可寻址大小。
7. 累加得到最大文件大小。

> ⭐考试重点

### 考试高频考点

* 一个索引块能存多少索引项。
* 直接索引、一级间接索引、二级间接索引可表示的文件大小。
* 教师强调例题 6.1 要会算。

### 常见简答题

* 什么是索引结构？
* 索引结构有什么优缺点？

### 常见计算题

* 给定块大小、索引项大小、直接/间接索引项数量，求最大文件长度。

### 易错点

* 索引块本身不是数据块，计算文件大小时不要把索引块容量当成文件数据容量。
* 一级间接和二级间接的指数关系容易算错。

### 一句话速记

* 索引题先算一个索引块能放几个地址，再分直接、一级、二级累加。
