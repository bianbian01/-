# 操作系统老师强调重点单独整理

## 一、总复习优先级

### 1. 最高优先级

- CPU 管理是“重中之重”。
- 存储管理/内存管理也是核心部分。
- 老师说 CPU 管理 + 存储管理大约占相关知识的接近 80%。

### 2. 重点大题方向

- CPU 调度算法：会算周转时间、带权周转时间。
- 进程同步与通信：重点是信号量、PV 操作、伪代码。
- 内存管理：页表、段表、二进制地址划分、物理地址计算。
- 页面置换：特别是 LRU 等算法。
- 磁盘调度：电梯算法等，数字会变，方法不变。
- 文件管理：多为概念题，也有索引结构、位示图等简单计算。

### 3. 考试题型提示

- 名词解释：大概 4-5 个。
- 简答题：大概 4-5 个。
- 应用题/设计题：常见 4 分、8 分，也可能 10 分。
- 不会也不要交白卷，老师改卷会看关键词。

### 4. 老师反复提醒的答题方式

- 概念题抓关键词即可，不一定要原文背诵。
- 计算题表格、步骤要写清楚。
- PV 题中信号量初值最关键。
- 地址计算题中二进制位数不能拆错。
- 如果 PV 伪代码不会写得很规范，可以写汉字说明结构，但 P/V 和信号量关系要清楚。

### 2. 第 8 页：用户态与内核态

老师说这是第一章第一个比较关键的知识点。

重点问题：

- 为什么要划分用户态和内核态？

核心关键词：

- 安全性。
- 可靠性。
- 保护系统资源。
- 防止用户程序随意执行特权操作。

考试方式：

- 老师明确说阅卷会找“安全性”这类关键词。

### 3. 第 16 页：中断技术、通道技术

老师强调：

- 多道程序设计要真正实现，需要硬件支持。
- 两个基础：中断、通道。

必须记：

- 中断用于 CPU 响应事件。
- 通道是专门处理 I/O 设备数据传输的处理器。
- 通道处理 I/O 设备，但不同于普通 CPU，没有自己的独立内存空间，需要使用主存。

可能考法：

- 填空题：多道程序设计实现的硬件基础是“中断”和“通道”。
- 名词解释：通道。

### 4. 中断处理过程

老师说书上可能写七步、九步，但考试写三步即可。

三步关键词：

1. 保护现场。
2. 处理中断。
3. 恢复现场。

老师原意：

- 不需要写得特别复杂，触发关键词就行。
- 这是关键点。

- 老师提到这两个对物联网专业有现实意义，但没有要求背标准定义。

## 三、第二章 CPU 管理 / 进程管理重点

### 1. 每章开头摘要

- 摘要能帮助了解本章相关内容。

### 2. 程序顺序执行与并发执行

老师点名：

- 程序顺序执行的三个特点。
- 并发执行的概念。

重点：

- 顺序执行：顺序性、封闭性、可再现性。
- 并发：关键是在“同一时间间隔内”多个程序推进。

### 3. 第 53 页：进程定义

老师点名进程定义。

重点表述：

- 进程是具有独立功能、可并发执行的程序关于某个数据集合的一次执行过程。
- 进程是操作系统进行资源分配和保护的基本单位。

可能考法：

- 名词解释：进程。

### 4. PCB

老师再次强调：

- 进程结构里最关键的是 PCB。
- 名词解释可能问 PCB 是什么。

必须记：

- PCB = Process Control Block，进程控制块。
- 进程实体 = 程序段 + 数据段 + PCB。
- PCB 是进程存在的重要标志。

### 5. 第 54 页：进程特征

老师点名：

- 动态性。
- 并发性。
- 独立性。
- 异步性。
- 结构性。

复习要求：

- 按简答/选择准备。

### 6. 第 55-56 页：进程状态转换

老师说这是“最基础的最基础”，一定要看明白。

必须掌握：

- 三态模型。
- 五态模型。
- 带挂起状态的模型。

重点不是死背，而是理解箭头：

- 就绪和运行为什么可以双向转换。
- 运行到阻塞为什么是单向。
- 阻塞在什么情况下回到就绪。
- 创建、终止如何加入五态模型。
- 挂起/激活与内存、外存交换的关系。

### 7. 第 64 页：原语与原子性

老师点名：

- 什么是原语？
- 什么是原子性？

核心答法：

- 一段代码要么不执行，要么完整执行。
- 执行时必须执行完，中间不能被打断。

### 8. 第 67 页：进程挂起与激活

老师说经常可能会考。

重点：

- 挂起和激活要理解作用。
- 可能和内存管理、内外存交换放在一起考。

### 9. 第 67 页：作业定义与组成

### 10. 第 69 页：CPU 三级调度

老师要求：

- 虚拟文件系统能连接不同文件系统，因为它定义了各种文件系统都支持的统一接口和数据结构。
