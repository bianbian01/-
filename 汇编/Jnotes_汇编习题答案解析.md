# 第1章 汇编语言基础

## 1.1 简答题

### （1）哪个处理器的指令系统称为 80x86 系列处理器的基本指令集？
**答：** Intel 8086/8088 的指令系统称为 80x86 系列处理器的基本指令集。  
**解析：** 后续 80286、80386、80486、Pentium 等都在兼容 8086/8088 基本指令集的基础上扩展。

### （2）ROM-BIOS 是什么？
**答：** ROM-BIOS 是固化在 ROM 中的基本输入输出系统。  
**解析：** 它在开机时完成硬件自检、初始化，并向系统或程序提供最基本的 I/O 服务。

### （3）什么是通用寄存器？
**答：** 通用寄存器是 CPU 内部可由程序员直接使用、用途相对灵活的高速存储单元。IA-32 中 8 个 32 位通用寄存器是：`EAX、EBX、ECX、EDX、ESI、EDI、EBP、ESP`。  
**解析：** EAX 常作累加器，EBX 常作基址，ECX 常作计数器，EDX 常作数据寄存器，ESI/EDI 常作源/目的变址，EBP/ESP 与堆栈相关。

### （4）堆栈的存取原则是什么？
**答：** 后进先出，LIFO/FILO。  
**解析：** 最后压入堆栈的数据最先被弹出。`PUSH` 入栈，`POP` 出栈。

### （5）标志寄存器主要保存哪方面的信息？
**答：** 标志寄存器主要保存指令执行结果的状态信息、控制信息和系统信息。  
**解析：** 常用状态标志包括 `CF、PF、AF、ZF、SF、OF`。

### （6）最高有效位 MSB 是指哪一位？
**答：** MSB 是一个二进制数中最左边、权值最高的一位。  
**解析：** 在有符号补码中，MSB 通常也是符号位：0 表示非负，1 表示负。

### （7）汇编语言中的标识符与高级语言变量/常量名的组成原则有本质区别吗？
**答：** 没有本质区别。  
**解析：** 都是用来给程序实体命名，一般由字母、数字、下划线等组成，并且不能与保留字冲突。

### （8）汇编语言标识符大小写不敏感意味着什么？
**答：** 表示同一标识符的大小写形式等价。  
**例：** `Again`、`again`、`AGAIN` 通常被 MASM 视为同一标识符。

### （9）END 语句后的语句会被汇编吗？
**答：** 不会。  
**解析：** `END` 表示源程序结束，后面的语句通常不再作为源程序汇编。

### （10）汇编时生成的列表文件主要包括哪些内容？
**答：** 通常包括源程序语句、机器代码、偏移地址、符号表、错误信息等。  
**解析：** 列表文件用于观察汇编后的代码、变量地址、机器码和调试信息。

## 1.2 判断题

1. **错/不严谨。** EAX 常称为累加器，但不是因为“使用最频繁”，而是因为历史上与算术逻辑运算联系最紧密。  
2. **错。** EIP 是专用寄存器，不属于通用寄存器。  
3. **对。** 实地址方式主要兼容 8086，地址形成以 16 位段地址和 16 位偏移为基础，不能充分发挥 IA-32 的 32 位能力。  
4. **错。** 保护方式下，段基地址加偏移地址形成的是线性地址，不一定直接就是物理地址；若启用分页，还需线性地址到物理地址转换。  
5. **错。** Windows 控制台环境不是 DOS 环境，Windows 下的虚拟 DOS 环境也不等同于控制台环境。  
6. **错。** `MOV` 是处理器指令，不是汇编语言的执行性“语句”本身；源程序语句经汇编后形成机器指令。考试若按教材语境，也可理解为“传送指令 MOV 属于可执行指令”。  
7. **错。** 汇编语句通常由 4 个部分组成，但不是都必须明显出现，也不一定都要用分隔符区分。  
8. **对。** MASM 注释以英文分号 `;` 开始，不是中文分号。  
9. **错。** 程序终止执行不等于汇编结束；运行时终止由执行流程决定，汇编结束由 `END` 等源程序结构决定。  
10. **对。** 源程序文件和列表文件都是文本性质文件。

## 1.3 填空题

1. Intel 8086 支持 **1MB** 容量主存空间，IA-32 处理器支持 **4GB** 容量主存空间。  
2. Intel **80386** 处理器将 80x86 指令系统升级为 32 位指令系统，**80486** 处理器内部集成浮点处理单元。  
3. IA-32 处理器有 8 个 32 位通用寄存器，其中 `EAX、EBX、ECX、EDX` 可分成 16 位和 8 位操作，另外 4 个是 `ESI、EDI、EBP、ESP`。  
4. EDX 是 **32** 位的，其中低 16 位名称是 **DX**；D0～D7 和 D8～D15 分别用 **DL** 和 **DH** 表示。  
5. IA-32 处理器有 **6** 个段寄存器，它们都是 **16** 位的。  
6. 复位后首先进入 **实地址** 工作方式；该方式分段最大不超过 **64KB**。  
7. 逻辑地址由 **段地址/段选择器** 和 **偏移地址** 两部分组成；代码段中下一条指令由 `CS` 和 **EIP** 指示，实地址模型中起作用的是 **IP**。  
8. Windows 文件夹对应的专业术语是 **目录**。  
9. 指令由表示功能的 **操作码** 和表示操作对象的 **操作数** 组成；IA-32 处理器的指令前缀属于 **可选** 部分。  
10. MASM 源文件扩展名是 **.ASM**；汇编生成 OBJ 的文件称为 **目标文件**；32 位 Windows 程序通常选择 **flat/平展** 存储模型。

## 1.4～1.16 简答补充

### 1.4 简述 Intel 80x86 系列处理器在指令集方面的发展
**答：** 8086/8088 建立基本指令集；80286 增加保护方式相关支持；80386 扩展为 32 位 IA-32 指令集；80486 集成浮点处理单元；Pentium 系列继续增加 MMX、SSE 等多媒体扩展；后续 Intel 64 扩展到 64 位并兼容 IA-32。

### 1.5 微型计算机系统硬件组成及作用
**答：** 主要包括 CPU、主存储器、I/O 接口、外部设备、总线等。CPU 运算控制，主存保存程序和数据，I/O 接口连接外设，总线传送地址、数据和控制信号。

### 1.6 什么是标志？状态标志、控制标志、系统标志是什么？
**答：** 标志是标志寄存器中的二进制位。状态标志反映运算结果，如 CF/ZF/SF/OF/PF；控制标志控制某些指令行为，如 DF 控制串操作方向；系统标志用于操作系统或处理器管理。状态标志在 EFLAGS 中的位置：CF=D0、PF=D2、AF=D4、ZF=D6、SF=D7、OF=D11。

### 1.7 平展、段式和实地址存储模型
**答：** 平展模型段基地址通常为 0，偏移地址近似等于线性地址；段式模型通过段选择器查段描述符，段基地址加偏移形成线性地址；实地址模型使用 `物理地址=段地址×16+偏移地址`。

### 1.8 实地址方式、保护方式和虚拟 8086 方式
**答：** 实地址方式兼容 8086，使用实地址存储模型；保护方式是 IA-32 正常工作方式，可使用平展或段式模型并支持分页、保护和多任务；虚拟 8086 方式是在保护方式下模拟 8086 环境。

### 1.9 IA-32 三类基本段
**答：** 代码段、数据段、堆栈段。代码段存放指令，数据段存放变量数据，堆栈段用于调用、返回、临时保存数据和参数。

### 1.10 高级语言、汇编语言、机器语言区别
**答：** 高级语言接近自然语言和算法表达；汇编语言用助记符表达机器指令；机器语言是 CPU 直接执行的二进制代码。汇编语言介于高级语言和机器语言之间，更接近硬件。

### 1.11 助记符、汇编语言、汇编程序、汇编器
**答：** 助记符是机器指令的符号化名称，如 MOV；汇编语言是用助记符和伪指令编写的低级语言；汇编语言程序是源程序；汇编器是把汇编源程序翻译为目标代码的软件。

### 1.12 路径概念
**答：** 绝对路径从根目录开始；相对路径相对于当前目录；当前目录是命令解释器当前所在目录。DOS 中提示找不到文件，可能是当前目录不正确，或未给出正确路径。

### 1.13 汇编语言语句两种，每种四部分
**答：** 分为执行性语句和说明性语句。一般由标号/名字、操作码/伪指令、操作数、注释四部分组成。

### 1.14 标识符和保留字
**答：** 标识符是用户定义的名字；保留字是汇编器已预定义、具有固定含义的词，不能作为普通标识符。标识符通常由字母、数字、下划线、@、?、$ 等组成，不能以数字开头，不能与保留字冲突。

### 1.15 自定义标识符判断
给出：`FFH, DS, Again, next, @data, h_ascii, 6364b, flat`。  
**可用：** `Again、next、h_ascii`。  
**不可用/不建议：** `DS` 是段寄存器名；`@data` 是预定义符号；`flat` 是存储模型相关保留字；`6364b` 以数字开头；`FFH` 是十六进制常量形式。

### 1.16 汇编程序开发四步骤
**答：** 编辑、汇编、连接、调试/运行。编辑生成 `.ASM`；汇编生成 `.OBJ` 和可选 `.LST`；连接生成 `.EXE`；调试运行检查结果。

# 第2章 数据表示和寻址

## 2.1 简答题

1. **8 位无符号数不能表示 257。** 8 位无符号范围是 0～255。  
2. **有区别。** 字符 `'F'` 是 ASCII 码，值为 46H；数值 `46H` 是十六进制数 46H。作为机器值二者相同，但语义不同。  
3. `(34+67H)*3` 可在汇编阶段计算，不随程序运行变化，故是常量表达式。  
4. A～F 开头的十六进制常数前加 0，是为了避免被识别为标识符。  
5. 500 不能作为 BYTE 初值，BYTE 无符号范围 0～255，有符号补码范围 -128～127。  
6. 多字节数据按对齐边界存放可提高访问效率。  
7. “寻址”就是寻找操作数所在位置或计算有效地址。  
8. `MOV EAX, VAR` 在 MASM 中变量名表示存储器操作数，直接给出变量的偏移地址作为地址形式，因此称直接寻址。  
9. `MOV EAX,[ESI]` 默认从 DS 段取得存储器操作数；若基址是 EBP/ESP 则默认 SS。  
10. 比例因子只支持 1、2、4、8，是因为常见数组元素大小为字节、字、双字、四字。

## 2.2 判断题

1. 对。  
2. 对，8421 BCD 中最高位权为 8。  
3. 错，大写字母 ASCII 码小于小写字母，所以升序时大写在小写前。  
4. 错，DB 占 1 字节，DD 占 4 字节。  
5. 对，`TYPE DX` 可理解为寄存器 DX 的字节数，结果为 2。  
6. 对，IA-32 采用小端方式存储多字节数据。  
7. 错，0403H 不是 4 的倍数，双字未按 4 字节边界对齐。  
8. 对，立即数只能出现在源操作数。  
9. 对，存储器寻址的操作数在主存中。  
10. 对，`[VAR+2]` 与 `VAR[2]` 等价。

## 2.3 填空题

1. `01100001B`：无符号数是 **97**；BCD 真值是 **61**；ASCII 字符是 **a**。  
2. 回车 CR ASCII 码 **0DH**；换行 LF ASCII 码 **0AH**。  
3. 定义字节变量伪指令是 **DB/BYTE**；取偏移地址操作符是 **OFFSET**。  
4. `H8843 DD 99008843H`，小端存放为 `43 88 00 99`，`MOV CX, WORD PTR [H8843]` 后 `CX=8843H`。  
5. DD 定义变量类型是 **DWORD/双字**；`TYPE XYZ=4`；若按字量使用，用 **WORD PTR**。  
6. `ABC DB 1,2,3`，`MOV CL,[ABC+2]` 后 `CL=03H`。  
7. 数据寻址方式：**立即数寻址、寄存器寻址、存储器寻址**。  
8. `MOV EAX, OFFSET MSG`：目的操作数为 **寄存器寻址**，源操作数为 **立即数寻址**。  
9. 有效地址 = `04000H + 20H*2 + 8 = 04048H`。  
10. EBX 作基址默认用 **DS** 段；BP/EBP/SP/ESP 作基址默认用 **SS** 段。

## 2.4～2.9 计算题

### 2.4 十六进制无符号数转十进制
1. FFH = 255  
2. 0H = 0  
3. 5EH = 94  
4. EFH = 239

### 2.5 十进制转压缩 BCD
1. 12 → 12H  
2. 24 → 24H  
3. 68 → 68H  
4. 99 → 99H

### 2.6 压缩 BCD 转十进制
1. 10010001B = 91  
2. 10001001B = 89  
3. 00110110B = 36  
4. 10010000B = 90

### 2.7 8 位补码
1. 0 → 00000000B  
2. 127 → 01111111B  
3. -127 → 10000001B  
4. -57 → 11000111B

### 2.8 十六进制加减与进/借位
1. `1234H + 7802H = 8A36H`，无进位。  
2. `F034H + 5AB0H = 14AE4H`，16 位结果 `4AE4H`，有进位。  
3. `C051H - 1234H = AE1DH`，无借位。  
4. `9876H - ABCDH = ECA9H`，有借位。

### 2.9 ASCII 常用范围
`'0'～'9'：30H～39H`；`'A'～'Z'：41H～5AH`；`'a'～'z'：61H～7AH`；`0DH` 是回车 CR，`0AH` 是换行 LF。

## 2.10 数据定义
```asm
.data
my1b byte 'Personal Computer',0
my2b byte 20
my3b byte 20h
my4b byte 10100b
my5w word 20 dup(?)
my6c equ 100
my7c equ <Personal Computer>
```
解析：字符串用 BYTE；十进制、十六进制、二进制用对应后缀；未赋值字变量用 `word 20 dup(?)`；符号常量用 `EQU`。

## 2.11 定义常量 NUM 和字数组 DATALIST
```asm
NUM equ 5
DATALIST word -10,2,5,4,?
```

## 2.12 按低地址到高地址写出分配值
```asm
db 'ABC',10,10h,'EF',3 dup(-1,?,3 dup(4))
```
依次为：`41H,42H,43H,0AH,10H,45H,46H`，然后重复 3 次：`FFH,00H,04H,04H,04H`（`?` 实际初值通常不关心，PPT 中常按 00H 显示）。

```asm
dw 10h,-5,3 dup(0)
```
小端按字节为：`10 00, FB FF, 00 00, 00 00, 00 00`。

## 2.13 EAX 内容
数据段：
```asm
varw dw 1234h,5678h
varb db 3,4
count1 equ $-varw
vard dd 12345678h
count2 equ $-vard
buff db 10 dup(0)
mess db 'hello'
count3 equ $-buff
```
答案：
- `mov eax, offset mess` → EAX 为 `mess` 的偏移地址。  
- `mov eax,count1` → `count1=6`。  
- `mov eax,count2` → `count2=4`。  
- `mov eax,count3` → `count3=15`，因为 buff 10 字节，mess 5 字节。

## 2.14 显示 ASCII 表
核心思路：双重循环。外层高 4 位从 20H、30H、40H、50H、60H、70H；内层低 4 位从 0～FH，组合为 ASCII 码并显示。

## 2.15 小端读取
```asm
var dd 12345678h
```
内存低到高：`78 56 34 12`。  
- `mov eax,[var]` → EAX=12345678H  
- `mov bx,word ptr [var]` → BX=5678H  
- `mov cx,word ptr [var+2]` → CX=1234H  
- `mov dl,byte ptr [var]` → DL=78H  
- `mov dh,byte ptr [var+3]` → DH=12H

## 2.16 IA-32 32 位寻址公式
有效地址 EA 的一般形式：
```text
EA = 基址寄存器 + 变址寄存器 × 比例因子 + 位移量
```
比例因子只能是 1、2、4、8；基址常用 EBX/EBP，变址常用 ESI/EDI，ESP 不能作变址寄存器。

## 2.17 源操作数寻址方式
1. `mov edx,1234h`：立即数寻址  
2. `mov edx,[dvar]`：直接寻址  
3. `mov edx,ebx`：寄存器寻址  
4. `mov edx,[ebx]`：寄存器间接寻址  
5. `mov edx,[ebx+1234h]`：寄存器相对寻址  
6. `mov edx,vard[ebx]`：寄存器相对寻址  
7. `mov edx,[ebx+edi]`：基址变址寻址  
8. `mov edx,[ebx+edi+1234h]`：相对基址变址寻址  
9. `mov edx,vard[esi+edi]`：相对基址变址寻址  
10. `mov edx,[ebp*4]`：不合法，EBP 不能作为比例变址寄存器使用。

# 第3章 通用数据处理指令

## 3.1 简答题

1. `MOV ESI, WORD PTR 250` 错在目的寄存器 ESI 是 32 位，而源操作数指定为 WORD 16 位；可改为 `MOV SI, WORD PTR [250]` 或 `MOV ESI, DWORD PTR [250]`，若是立即数则写 `MOV ESI,250`。  
2. `XCHG EDX,CX` 错，因为 EDX 是 32 位，CX 是 16 位，类型不一致。  
3. 堆栈向下生长：压入数据时 ESP 减小，栈顶向低地址方向移动。  
4. `LEA EBX,[ESI]` 正确，因为运行时计算有效地址；`MOV EBX, OFFSET [ESI]` 错，因为 OFFSET 只能取得汇编时确定的偏移地址。  
5. 加法后 ZF=1 表示运算结果为 0。  
6. 单操作数指令的操作数既是源操作数又是目的操作数。  
7. 大小写转换利用 ASCII 码中大小写字母相差 20H 的规律。  
8. 加减法本身不区分有符号/无符号；程序员根据 CF 判断无符号越界，根据 OF 判断有符号溢出。  
9. `DIV ESI` 在 32 位除法中，被除数是 `EDX:EAX`，除数是 ESI，商在 EAX，余数在 EDX。  
10. 逻辑与每一位相当于乘法规则：只有 1 AND 1 得 1，其余为 0，所以也称逻辑乘。

## 3.2 判断题

1. 错，MOV 不影响 ZF。  
2. 错，NOP 是空操作指令，不是“没有指令”。  
3. 错，堆栈遵循后进先出，但 CALL/RET/INT/IRET 等也会使用堆栈。  
4. 对，ADD/SUB 执行结果会影响标志，但执行前标志通常不影响结果。  
5. 对，80-90 需要借位，CF=1。  
6. 错，INC ECX 不影响 CF，而 ADD ECX,1 会影响 CF，不能完全互换。  
7. 对，零扩展数值不变；符号扩展保持有符号值不变。  
8. 错，CMP 相当于减法设置标志，但不保存结果，与 SUB 不完全相同。  
9. 对，逻辑运算没有进位/溢出，AND/OR/XOR 会使 CF=OF=0。  
10. 错，SHL 左移 1 位是乘 2，不是乘 10。

## 3.3 填空题

1. `PUSH DS` 后 ESP **减 2**。  
2. `POP EDX` 可由 **MOV** 和 **ADD** 实现。  
3. 例3-3 TAB 若为 `1234567890`，原 num 为 `6,7,7,8,3,0,0,0`，显示结果是 **78894111**。  
4. `BAH+6CH=126H`，8 位结果 **26H**，最低字节 1 的个数为 3，PF=0；`45BAH+786CH=BE26H`，最低字节仍为 26H，PF=0。  
5. AX=0098H，执行 `NEG AX` 后 AX=FF68H，SF=1。  
6. CL=98H，`MOVZX DX,CL` 后 DX=0098H，称为 **零扩展**。  
7. CL=98H，`MOVSX DX,CL` 后 DX=FF98H，称为 **符号扩展**。  
8. `XOR EAX,EAX` 和 `SUB EAX,EAX` 后 EAX=0；前者 CF=OF=0，后者 CF=OF=0；`MOV EAX,0` 后 EAX=0，但 CF/OF 不变。  
9. 例3-9 中若执行 XLAT 查表，AL=8 时得到 table[8]，即 12H。  
10. `SHR EDX,4` 可使 EDX 中无符号数除以 16。

## 3.5 指令错误原因
1. `mov ecx,dl`：32 位与 8 位类型不一致。  
2. `mov eip,ax`：EIP 不能作为普通目的操作数直接修改。  
3. `mov es,1234h`：立即数不能直接送段寄存器。  
4. `mov es,ds`：段寄存器之间不能直接传送，应借助 AX。  
5. `mov al,300`：300 超出 AL 的 8 位范围。  
6. `mov [esi],45h`：内存操作数类型不明确。  
7. `mov eax,ebx+edi`：不能把地址表达式直接作为源寄存器运算；应 `lea eax,[ebx+edi]`。  
8. `mov 20h,ah`：立即数不能作目的操作数。

# 第4章 程序结构

## 4.1 简答题

1. CPUID 返回厂商字符串首字母 “G” 在 EBX 中。  
2. 数据的直接寻址是访问内存数据；指令的直接寻址是转移目标地址直接由指令给出。  
3. 相对寻址只需保存位移量，代码可重定位，指令短，适用范围广，所以使用最多。  
4. Jcc 只能在代码段内相对转移，不能跳到代码段外。  
5. 奇偶校验是检查数据中 1 的个数为奇数或偶数的校验方法。  
6. JZ 和 JE 都测试 ZF=1，所以是同一机器条件的两个助记符。  
7. 无符号大小看 CF/ZF，有符号大小看 SF/OF/ZF，所以条件转移不同。  
8. 双分支之间的 JMP 用来跳过另一个分支，回到共同出口。  
9. 若循环体超过短转移范围，不能直接使用 LOOP 短转移，可改用 DEC/JNZ 或反向条件跳转+JMP。  
10. “先循环后判断”是 do-while/repeat 结构，循环体至少执行一次。

## 4.2 判断题

1. 对。改变 EIP/CS:EIP 会引起流程跳转。  
2. 错，相对寻址不一定都是近转移，也有短转移等。  
3. 错，寄存器间接寻址目标地址来自寄存器，不来自存储单元。  
4. 错，JMP 类似 GOTO，但可以使用。  
5. 错，Jcc 利用标志，但自身不影响标志。  
6. 错，JA 是无符号大于，JG 是有符号大于。  
7. 对，JC 和 JB 都对应 CF=1，但语义分别偏进位和无符号低于。  
8. 错，控制循环是否结束可在循环前、循环中或循环后判断。  
9. 对，LOOP 不影响标志；DEC 会影响除 CF 以外的状态标志。  
10. 错，ECX=0 时 LOOP 会转移，JECXZ 也会转移，但二者含义不同。

## 4.3 填空题

1. JMP 按范围和寻址方式可分为：段内转移 **相对寻址**，段内转移 **间接寻址**，段间转移 **直接寻址**，段间转移 **间接寻址**。  
2. 短、近、远转移类型名：**SHORT、NEAR、FAR**。  
3. `JMP EBX` 后 EIP=1256H；`JMP TABLE[EBX]`：TABLE 偏移 20A1H，EBX=1256H，有效地址=32F7H，内存 32F7H 处存放 3280H，故 EIP=3280H。  
4. `CMP EAX,3721H` 后接 JZ，转移条件是 EAX=3721H，此时 ZF=1。  
5. `SHR EBX,4` 后 JNC 转移说明最后一次移出的位 CF=0，即原 EBX 的 D3=0。  
6. EDX=0 可写 `CMP EDX,0` 或 `TEST EDX,EDX`，然后 `JE`。  
7. 循环结构由 **循环初始、循环体、循环控制** 三部分组成。  
8. JECXZ 转移条件是 **ECX=0**；LOOP 不发生转移条件是 **ECX-1=0**。  
9. 例4-14 删除 LOOP 后可用：`cmp ebx, ecx` 与 `jb again`。  
10. 英文中 e 频率最高，若密文 8FH 最多，key 可能为 `8FH XOR 'e'(65H)=EAH`。

# 第5章 模块化程序设计

## 5.1 简答题

1. `CALL EBX` 采用 **寄存器间接寻址**。  
2. MASM 用 PROC 定义子程序，是为了让汇编器知道过程范围、调用属性和符号类型。  
3. 子程序注释说明入口参数、出口参数、破坏寄存器和功能，便于调用和维护。  
4. 传值传递数据本身，传址传递数据地址；传址可修改原数据。  
5. 堆栈传参要保持堆栈平衡，否则 RET 返回地址或调用者环境会错。  
6. INCLUDE 包含源文件文本；INCLUDELIB 告诉连接器使用库文件。  
7. 子程序库是多个可复用子程序的集合。  
8. 宏无形参而给实参，汇编时会出错。  
9. 宏中标号用 LOCAL，是为了每次宏展开时生成唯一局部标号，避免重复定义。  
10. 条件汇编不成立的语句不会进入目标代码/可执行文件。

## 5.2 判断题

1. 错，PROC 是伪指令，不是处理器指令。  
2. 错，CALL 会压入返回地址，影响 ESP。  
3. 对，CALL 指令本身不包含高级语言式参数，参数通常由寄存器/变量/堆栈另行传递。  
4. 对，子程序内再 CALL 是嵌套调用。  
5. 错，出口参数寄存器不能保护后又恢复，否则返回值被覆盖。  
6. 对，INCLUDE 的源文件相当于源程序一部分。  
7. 错，宏调用不是 CALL，而是汇编时文本展开。  
8. 对，宏定义一般写在调用之前。  
9. 错，重复汇编是条件汇编/宏等预处理机制，不一定要先定义再调用。  
10. 对，条件汇编由汇编器在汇编时根据条件决定是否汇编。

## 5.3 填空题

1. `RET i16` 相当于 `RET` 和 `ADD ESP, i16`。  
2. 例5-1 若用 `POP EBP` 和 `JMP EBP` 替换 RET，则 EBP 内容是 **返回地址 retp1**。  
3. 参数传递主要三种：**寄存器、共享变量、堆栈**。  
4. 10 的二进制是 1010，十六进制是 0AH；加 37H 得 41H，是字符 **A** 的 ASCII 值。  
5. 堆栈传参时寻址堆栈段数据的寄存器通常是 **EBP**。  
6. 声明公共变量用 **PUBLIC**；使用外部变量用 **EXTERN/EXTRN**。  
7. `TEST PROC` 对应结束 `TEST ENDP`；`DISP MACRO` 对应结束 `ENDM`。  
8. `WriteChar MACRO CHAR:REQ`，宏名是 **WriteChar**，参数 1 个，`:REQ` 表示 **必需参数**。  
9. `DB 20 DUP(20H)` 可用 `REPT 20 / DB 20H / ENDM` 实现。第一句 `REPT 20`，第二句 `DB 20H`，第三句 `ENDM`。  
10. `IF NUM LT 100` 中 LT 表示 **小于**，配合 **ENDIF**。

## 5.4 改错
原程序错误：`push eax` 后又要通过 EDX:EAX 返回结果，最后未恢复/处理不当；同时应保护调用者需要的寄存器。可改为：
```asm
crazy PROC
    push ebx
    push ecx
    xor eax,eax
    xor edx,edx
again:
    add eax,[ebx]
    adc edx,0
    add ebx,4
    loop again
    pop ecx
    pop ebx
    ret
crazy ENDP
```
解析：EAX/EDX 是返回值，不能用 push/pop 恢复旧值覆盖。

## 5.5 ASCII 两位十进制转压缩 BCD
入口 DH=十位 ASCII，DL=个位 ASCII；出口 AL=BCD：
```asm
sub dh,30h
sub dl,30h
mov al,dh
shl al,4
or al,dl
ret
```

## 5.6 用 AAM 把 AL 中 0～99 数值转 ASCII
```asm
xor ah,ah
aam
add ax,3030h
```
AAM 后 AH=十位，AL=个位，再加 3030H 变 ASCII。

## 5.7～5.24 程序设计题要点
5.7：读取按键，若 ASCII=08H 退出，否则调用 HTOASC 显示 ASCII 码。  
5.8：显示 EAX 的 32 位二进制：循环 32 次，移出最高位，显示 0/1。  
5.9：把 32 位寄存器改为 16 位寄存器，只输出 -2^15～2^15-1 范围。  
5.10：无符号十进制输入：逐字符判断 '0'～'9'，累加 `result=result*10+digit`。  
5.11：校验和：逐字节累加，结果返回和；入口含数据个数和缓冲区首地址。  
5.12：分别用寄存器、temp 变量、堆栈传递 32 位数，调用同一显示子程序。  
5.13：DISPMEM：入口 EAX=主存偏移地址，ECX=字节数；循环调用 DISPHB 显示每字节。  
5.14：主程序输入 10 个数，调用平均值子程序并显示；子程序文件定义输入、平均值、显示三个过程。  
5.15：宏定义是宏体模板；宏调用是使用宏名；宏指令是宏调用形式；宏展开是汇编器把宏体替换到调用处；宏汇编是进行宏处理的汇编过程。  
5.16：宏用 `MACRO ... ENDM` 定义，用宏名调用。  
5.17：子程序运行时 CALL/RET，有独立入口，可重复调用但有开销；宏在汇编时展开，速度快但代码可能膨胀。  
5.18：SWAP 宏可用寄存器或内存操作数，借助临时寄存器交换两个操作数。  
5.19：LOGICAL 宏可对 AND/OR/XOR/TEST 等三操作数形式展开；NOT 是单操作数，需单独设计宏。  
5.20：`defstr msg,4,<Chapter 4:Program Structure>` 展开为 `msg4 db 'Chapter 4:Program Structure',0`；`defstr msg,5,<Chapter 5:Procedure Programming>` 展开为 `msg5 db 'Chapter 5:Procedure Programming',0`。  
5.21：`movestr strN,dstr,sstr` 可用 `rep movsb` 或循环实现，把 sstr 的 strN 个字符复制到 dstr。  
5.22：可写 `100 DUP(? )` 或用重复汇编生成 100 个 WORD，高字节依次为 2,4,6,...,200，低字节为 0，即字值依次为 0200H,0400H,...,C800H。  
5.23：宏结构中使用条件汇编：若 COUNT>5，则重复汇编 `ADD EAX,EAX` 10 次，否则不生成。  
5.24：FINSUM 宏：比较 `varx` 与 `vary`；若 `varx>=vary`，`sum=varx+8*vary`；否则 `sum=4*varx+vary`，可用 SHL/LEA 优化乘 8 和乘 4。
