## 0. 总体考试重点

### 0.1 最高优先级

老师反复强调：**CPU 管理 + 存储管理是最核心内容**，相关知识大约接近 80%。

优先级建议：

1. 第二章：进程管理、CPU 调度算法。
2. 第三章：同步互斥、信号量、PV 操作、死锁。
3. 第四章：存储管理、分页/分段/段页式、页面置换。
4. 第五章：I/O 控制方式、通道、磁盘调度。
5. 第六章：文件系统概念、索引结构、位示图。
6. 第一章：概念、特征、用户态/内核态、中断、通道、PSW。

### 0.2 高频大题方向

- CPU 调度：会画调度顺序，算完成时间、周转时间、带权周转时间。
- PV 操作：会判断同步/互斥关系，设信号量初值，写 P/V 伪代码。
- 地址转换：会拆页号、页内位移、段号、段内位移，查表并判断越界。
- 页面置换：会按 FIFO、OPT、LRU 算缺页次数和缺页率。
- 磁盘调度：会按 FCFS、SSTF、SCAN/电梯等算法写访问顺序并算总移动道数。
- 文件管理：会区分 FCB/FAT/JCB/PCB，掌握索引结构和位示图计算。

### 0.3 答题要求

- 名词解释：写出定义 + 关键词 + 作用即可，不必死背原文。
- 简答题：关键词一定要出现，例如“安全性”“可靠性”“保护资源”。
- 计算题：表格、步骤、公式要清楚，过程分很重要。
- PV 题：信号量初值最关键；伪代码不规范时，可以用汉字辅助说明。
- 地址题：二进制位数不能拆错，先看页面大小/段表长度/页表项。

### 1.2 名词解释高频

**操作系统**

管理和控制计算机软硬件资源，组织程序运行，并为用户和应用程序提供接口的系统软件。

关键词：资源管理、控制程序执行、用户接口、系统软件。

**PSW**

PSW 是 Program Status Word，程序状态字，用于保存程序运行状态、条件码、中断状态、CPU 工作状态等信息。

**通道**

通道是专门处理 I/O 设备数据传输的处理器。它不同于普通 CPU，一般没有独立内存空间，需要使用主存。

**中断**

CPU 暂停当前程序，转去处理突发事件，处理完成后再返回原程序继续执行的机制。

### 1.3 简答题高频

**操作系统设计目标**

- 方便性。
- 有效性。
- 可扩充性。
- 可移植性。
- 可靠性。
- 开放性。

**操作系统主要功能**

- 处理器管理。
- 存储管理。
- 设备管理。
- 文件管理。
- 用户接口。

注意：老师强调，主要功能不只是四大资源管理，还要加“用户接口”。

**操作系统基本特征**

- 并发。
- 共享。
- 虚拟。
- 异步。

**为什么要划分用户态和内核态**

标准答法：

为了保证系统的安全性和可靠性，保护系统资源，防止用户程序随意执行特权操作或破坏内核数据。

关键词：安全性、可靠性、保护系统资源、特权操作。

**中断处理三步**

1. 保护现场。
2. 处理中断。
3. 恢复现场。

**多道程序设计的硬件基础**

- 中断。
- 通道。

- 第 75 页开始：处理器调度算法。

### 2.2 名词解释高频

**进程**

进程是具有独立功能、可并发执行的程序关于某个数据集合的一次执行过程，是操作系统进行资源分配和保护的基本单位。

**PCB**

PCB 是 Process Control Block，进程控制块。它保存进程标识、状态、调度信息、资源信息、现场信息等，是进程存在的重要标志。

**原语**

原语是由若干条指令组成、用于完成特定系统功能的一段程序，执行时不可中断。

**原子性**

一段操作要么不执行，要么完整执行，执行过程中不能被打断。

**作业**

作业是用户提交给操作系统完成的一项任务，通常由程序、数据、作业说明书组成。

### 2.3 简答题高频

**程序顺序执行的特点**

- 顺序性。
- 封闭性。
- 可再现性。

**并发执行的核心**

多个程序在同一时间间隔内交替推进。

注意：并发强调“同一时间间隔”，并行强调“同一时刻”。

**进程实体**

```text
进程实体 = 程序段 + 数据段 + PCB
```

**进程特征**

- 动态性。
- 并发性。
- 独立性。
- 异步性。
- 结构性。

**进程三态**

- 就绪态：具备运行条件，只缺 CPU。
- 运行态：正在 CPU 上执行。
- 阻塞态：等待某事件完成。

常见转换：

- 就绪 -> 运行：被调度。
- 运行 -> 就绪：时间片到或被抢占。
- 运行 -> 阻塞：请求 I/O 或等待事件。
- 阻塞 -> 就绪：等待事件完成。

易错点：阻塞态不能直接变运行态，必须先回到就绪态。

**三级调度**

- 高级调度：作业调度，从外存后备队列选择作业进入内存。
- 中级调度：内存调度，负责挂起与激活，涉及内外存交换。
- 低级调度：进程调度，从就绪队列选择进程占用 CPU。

口诀：高作业，中挂激，低选 CPU。

**抢占式与非抢占式**

- 非抢占式：进程主动放弃 CPU 前不会被强制剥夺。
- 抢占式：系统可因时间片到、高优先级进程到达等原因剥夺 CPU。

### 2.4 计算题高频：CPU 调度算法

必须掌握：

- FCFS：先来先服务。
- SJF/SPF：短作业/短进程优先。
- HRRN：高响应比优先。
- RR：时间片轮转。

常用公式：

```text
完成时间 = 作业结束运行的时刻
周转时间 = 完成时间 - 到达时间
带权周转时间 = 周转时间 / 服务时间
响应比 = (等待时间 + 服务时间) / 服务时间
平均周转时间 = 周转时间总和 / 作业数
平均带权周转时间 = 带权周转时间总和 / 作业数
```

做题模板：

1. 按题目指定算法画甘特图或调度表。
2. 写每个作业的完成时间。
3. 计算周转时间。
4. 计算带权周转时间。
5. 求平均值。

老师提醒：第二章课后作业一定要会算，尤其第三题、第四题相关内容。

## 3. 第三章 进程同步、通信与死锁

### 3.1 必看页码

- 第 97 页：临界资源、临界区。
- 第 103 页：信号量机制。
- 第 147 页开始：死锁。
- 第 153 页：安全状态与不安全状态。
- 第 158 页：死锁检测与解除、资源分配图。

### 3.2 名词解释高频

**同步**

多个进程之间存在执行先后顺序或协作关系，需要相互等待、相互配合。

**互斥**

多个进程不能同时访问同一个临界资源。

**临界资源**

一次只允许一个进程访问的资源。

**临界区**

进程中访问临界资源的代码段。

**信号量**

表示资源数量或同步条件的整型变量，只能通过 P/V 原语操作。

**死锁**

多个进程因竞争资源而互相等待，若无外力作用都无法继续推进的状态。

### 3.3 简答题高频

**同步与互斥区别**

- 同步看执行先后关系。
- 互斥看是否争用同一临界资源。

口诀：同步看先后，互斥看共享。

**临界区访问原则**

- 空闲让进。
- 忙则等待。
- 有限等待。
- 让权等待。

**P/V 操作含义**

- P 操作：申请资源或等待条件，通常使信号量减 1。
- V 操作：释放资源或发出完成信号，通常使信号量加 1。

**死锁四个必要条件**

1. 互斥条件。
2. 不剥夺条件。
3. 请求并保持条件。
4. 循环等待条件。

**安全状态**

系统存在某种安全序列，使所有进程都能顺利获得资源并完成，则系统处于安全状态。

### 3.4 设计题高频：PV 操作

老师明确说：信号量机制是“重中之重”。

PV 题步骤：

1. 判断题目是互斥、同步，还是二者都有。
2. 找临界资源，设置互斥信号量，初值通常为 1。
3. 找先后关系，设置同步信号量，初值通常为 0。
4. 先 P 后进入，完成后 V。
5. 伪代码结构要清楚，必要时用汉字说明。

互斥模板：

```text
semaphore mutex = 1;

P(mutex);
访问临界资源;
V(mutex);
```

前驱关系模板：

```text
semaphore s = 0;

进程 A:
    A 操作;
    V(s);

进程 B:
    P(s);
    B 操作;
```

生产者-消费者常见信号量：

```text
semaphore empty = 缓冲区容量;
semaphore full = 0;
semaphore mutex = 1;
```

必须看懂：

- 生产者-消费者问题。
- 读者-写者问题。
- 哲学家进餐问题。
- 书上爸爸妈妈儿子女儿/水果类例题。

可略：

- 管程不考。
- 3.7 通信不考。
- 理发师问题老师说不用重点看。
- 缓冲机制感兴趣看，不感兴趣可略。

### 3.5 死锁题重点

重点掌握：

- 死锁定义。
- 死锁产生条件。
- 可抢占资源与不可抢占资源。
- 安全状态与不安全状态。
- 资源分配图中圆圈、方框、小点、箭头含义。

银行家算法：难点但不是重点，看懂教材类似例题即可。

### 4.2 名词解释高频

**逻辑地址**

程序中使用的地址，也叫相对地址或虚地址。

**物理地址**

内存中的实际地址。

**静态重定位**

程序装入内存前完成地址转换，装入后地址不再改变。

**动态重定位**

程序运行过程中由硬件地址变换机构完成逻辑地址到物理地址的转换。

**虚拟存储器**

把内存和外存结合起来，使用户感觉拥有比实际内存更大的存储空间。

### 4.3 简答题高频

**分区存储管理**

要掌握：

- 单一连续分区。
- 固定分区。
- 可变分区。

**可变分区分配算法**

- 首次适应 FF。
- 循环首次适应 NF。
- 最佳适应 BF。
- 最坏适应 WF。

易错点：“最佳/最坏”不是说性能绝对最好或最坏，而是选择空闲区的策略不同。

**覆盖与交换**

- 覆盖：把不会同时执行的程序段共用同一内存区域。
- 交换：把暂时不用的进程换出到外存，需要时再换入内存。

**为什么要引入多级页表**

减少页表本身占用的内存空间，并扩大可管理的虚拟地址范围。

**为什么虚拟内存适合按页换入换出**

页大小固定，便于管理和交换；分段长度不一，换入换出实现较复杂。

### 4.4 计算题高频：分页地址转换

老师强调：分页是“重中之重”。

分页核心：

- 程序划分成等长页。
- 内存划分成同样大小的物理块。
- 逻辑地址由页号和页内位移组成。
- 查页表得到物理块号。

公式：

```text
逻辑地址 = 页号 P + 页内位移 W
物理地址 = 物理块号 F * 页面大小 + 页内位移 W
```

做题步骤：

1. 根据页面大小确定页内位移位数。
2. 把逻辑地址拆成页号和页内位移。
3. 查页表，判断页号是否越界。
4. 得到物理块号。
5. 计算物理地址。

易错点：

- 页面大小决定页内位移位数。
- 页号不存在就是越界。
- 二进制拆位不能错。

### 4.5 计算题高频：分段地址转换

分段核心：

- 分段按程序逻辑结构划分。
- 各段长度可以不同。
- 段表通常包含段基址和段长。

公式：

```text
逻辑地址 = 段号 S + 段内位移 W
物理地址 = 段基址 + 段内位移 W
```

做题步骤：

1. 查段号是否存在。
2. 比较段内位移和段长，判断是否越界。
3. 若不越界，物理地址 = 段基址 + 段内位移。

易错点：段表比页表多“段长”，必须判断段内位移是否超过段长。

### 4.6 计算题高频：段页式

段页式是先分段，再分页。

做题步骤：

1. 根据段号查段表，找到该段页表位置和段长。
2. 判断段内地址是否越界。
3. 把段内地址拆为页号和页内位移。
4. 查页表得到物理块号。
5. 拼出或算出物理地址。

### 4.7 计算题高频：页面置换算法

必须会：

- FIFO：先进先出。
- OPT：最佳置换，淘汰未来最长时间不再访问的页。
- LRU：最近最久未使用，淘汰过去最长时间没被访问的页。

老师对 LRU 的理解提示：

- OPT 需要预知未来，实际不可实现。
- LRU 用过去推测未来。
- 刚访问过的内容及其附近内容可能再次被访问。

做题步骤：

1. 画页框表。
2. 按访问序列逐个处理。
3. 命中不缺页，不置换。
4. 未命中则缺页，按指定算法换页。
5. 统计缺页次数和缺页率。

公式：

```text
缺页率 = 缺页次数 / 访问总次数
```

### 5.2 名词解释高频

**字符设备**

以字符为单位传输数据的设备，如键盘、打印机等。

**块设备**

以数据块为单位传输数据的设备，如磁盘。

**SPOOLing**

假脱机技术，通过磁盘缓冲和队列管理，把独占设备改造成逻辑上的共享设备。

**通道**

专门负责 I/O 设备数据传输的处理器，需要使用主存。

### 5.3 简答题高频

**设备按信息传输单位分类**

- 字符设备。
- 块设备。

**设备按资源分配方式分类**

- 独占设备。
- 共享设备。
- 虚拟设备。

**四种 I/O 控制方式**

- 程序直接控制方式。
- 中断控制方式。
- DMA 方式。
- 通道方式。

重点：第 253 页四种方式对比表，硬件和接口细节不用过深。

**Cache 与缓冲区区别**

- Cache 通常用于提高 CPU 与内存之间的数据访问速度。
- 缓冲区通常用于协调 I/O 设备与主机之间速度不匹配。
- 二者存放的数据、服务对象、目的不同。

**设备分配四张表**

- 系统设备表 SDT。
- 设备控制表 DCT。
- 控制器控制表 COCT。
- 通道控制表 CHCT。

### 5.4 计算题高频：磁盘调度

必须会：

- FCFS：先来先服务。
- SSTF：最短寻道时间优先。
- SCAN：电梯算法。
- C-SCAN：循环扫描。

做题步骤：

1. 看初始磁头位置。
2. 看请求队列。
3. 看题目指定算法。
4. 若是 SCAN/C-SCAN，要看初始移动方向。
5. 写出访问顺序。
6. 逐段计算磁头移动距离。
7. 求总移动道数。

老师提醒：磁盘调度数字容易变，但方法不变；千万不能把算法顺序搞错。

重点题：第 282 页应用题第 3 题，考试喜欢改数字考。

### 6.2 名词解释高频

**FCB**

FCB 是 File Control Block，文件控制块，保存文件名、文件属性、物理地址等文件管理信息。

**FAT**

FAT 是 File Allocation Table，文件分配表，用于记录文件所占磁盘块之间的链接关系。

**JCB**

JCB 是 Job Control Block，作业控制块。

**PCB**

PCB 是 Process Control Block，进程控制块。

**VFS**

VFS 是虚拟文件系统，它为不同文件系统提供统一接口和统一数据结构，使操作系统能以统一方式管理不同文件系统。

注意：VFS 严格意义上不是磁盘上固定存在的实体，主要存在于内存中，使用时建立，关闭后相关结构消失。

### 6.3 简答题高频

**文件管理系统核心作用**

帮助用户以文件名形式管理文件，实现按名存取。

**文件分类**

- 目录文件。
- 一般文件。
- 块文件。

也要能联系普通文件、目录文件、特殊文件等分类表述。

**文件组织结构**

- 逻辑结构：从用户角度看到的文件组织形式。
- 物理结构：从磁盘实际存放角度看到的文件组织形式。

**文件物理结构**

- 连续结构。
- 链接结构。
- 索引结构。

链接结构：

- 隐式链接。
- 显式链接，典型代表是 FAT。

**文件目录作用**

目录是一种数据结构，把文件名、物理地址、属性等组织起来，用于文件检索和按名存取。

关键词：文件检索、文件名、索引结构。

### 6.4 计算题高频：索引结构

重点页码：第 295 页，例 6.1。

常考内容：

- 直接索引。
- 一级间接索引。
- 二级间接索引。
- 三级间接索引。
- 根据索引块大小、地址项大小、盘块大小计算文件最大长度或访问盘块。

做题思路：

1. 算一个索引块能放多少个地址项。
2. 直接索引能管理多少数据块。
3. 一级间接索引能管理多少数据块。
4. 二级/三级间接索引按乘方扩展。
5. 换算成文件最大字节数或块数。

### 6.5 计算题高频：位示图

重点页码：第 309 页。

核心思想：

```text
一个 bit 对应一个磁盘块
0/1 表示空闲或占用，按题目规定
```

空间大小：

```text
位示图大小 = 磁盘块数 bit
字节数 = ceil(磁盘块数 / 8)
```

行列与块号转换：

若每行有 `w` 位，且行号、列号从 0 开始：

```text
块号 = 行号 * w + 列号
行号 = 块号 / w
列号 = 块号 % w
```

若题目行号、列号从 1 开始：

```text
块号 = (行号 - 1) * w + (列号 - 1)
```

老师提醒：按题意处理行列关系，关键是会算，不要在 0 开始还是 1 开始上脱离题目乱纠结。

## 9. 最后 10 分钟速背清单

- 用户态/内核态：安全性、可靠性、保护资源。
- 中断三步：保护现场、处理中断、恢复现场。
- 多道程序硬件基础：中断、通道。
- 进程实体：程序段 + 数据段 + PCB。
- PCB：进程存在的重要标志。
- 三级调度：高作业、中挂激、低进程。
- 周转时间 = 完成时间 - 到达时间。
- 带权周转时间 = 周转时间 / 服务时间。
- 同步看先后，互斥看共享。
- PV 题：信号量初值最关键。
- 死锁四条件：互斥、不剥夺、请求并保持、循环等待。
- 分页：物理地址 = 块号 * 页面大小 + 页内位移。
- 分段：物理地址 = 段基址 + 段内位移。
- FIFO/OPT/LRU：按题目算法逐步画页框。
- SPOOLing：假脱机，把独占设备改造成逻辑共享设备。
- 磁盘调度：先写访问顺序，再算总移动道数。
- FCB/FAT/JCB/PCB：文件控制块、文件分配表、作业控制块、进程控制块。
- 位示图：一位对应一块，0/1 看题目规定。
