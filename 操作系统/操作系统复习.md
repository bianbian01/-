# 操作系统复习提纲

> 来源：本文件夹内现有 `操作系统.md`、老师课堂重点转写、第一至第六章课件 PDF 目录结构、课本页码提示整理。  
> 复习优先级按老师强调：CPU/进程管理、进程同步与通信、存储管理约占主要分值；设备管理和文件管理偏概念与常见计算。

## 0. 考试重点总览

### 0.1 题型与高频考点

- 名词解释：约 4-5 个。重点背关键词，不要空白。
- 填空/选择：概念、分类、缩写、关键步骤。
- 简答：约 4-5 个。抓核心关键词即可。
- 应用/设计/计算题：常见 4 分、8 分或 10 分。

### 0.2 老师明确强调的大题方向

1. CPU/处理器调度：会画调度过程，算周转时间、带权周转时间。
2. PV 操作与信号量：会根据同步/互斥关系写伪代码，信号量初值是关键。
3. 地址转换：页表、段表、段页式，判断越界并算物理地址。
4. 页面置换：FIFO、OPT、LRU 等，算缺页次数/缺页率。
5. 磁盘调度：FCFS、SSTF、SCAN/电梯算法等，算磁头移动总道数。
6. 文件管理：FCB、FAT、索引结构、位示图等概念和简单计算。

### 0.3 复习策略

- 概念题：背“定义 + 关键词 + 用途/区别”。
- 计算题：必须写清表格、步骤、单位；数字变，方法不变。
- PV 题：先画前驱图或列约束，再定信号量初值，最后写 P/V。
- 地址题：先拆地址位数，再查表，再判断越界，最后拼/加物理地址。

## 第一章 引论

### 1.1 操作系统定义

操作系统是管理和控制计算机硬件与软件资源，合理组织计算机工作流程，并为用户和应用程序提供接口的一组系统软件。

关键词：资源管理、控制程序执行、提供接口、系统软件。

### 1.2 操作系统设计目标

- 方便性：让用户更方便地使用计算机。
- 有效性：提高系统资源利用率和吞吐量。
- 可扩充性：便于增加新功能、适应新硬件。
- 开放性：遵循标准，便于互联互通。

### 1.3 操作系统主要功能

- 处理器管理：进程/线程、调度、同步、通信。
- 存储管理：内存分配、地址转换、虚拟存储。
- 设备管理：I/O 控制、缓冲、设备分配、磁盘调度。
- 文件管理：文件组织、目录、存储空间管理。
- 用户接口：命令接口、程序接口、图形界面等。

### 1.4 操作系统基本特征

- 并发：多个程序在同一时间间隔内推进。
- 共享：系统资源可被多个并发执行的程序共同使用。
- 虚拟：把一个物理实体变成多个逻辑实体，或把多个物理实体变成一个逻辑实体。
- 异步：进程推进速度不可预知，执行结果应保持正确。

### 1.5 操作系统分类

- 批处理系统：单道批处理、多道批处理。
- 分时系统：多用户交互，共享 CPU，响应时间重要。
- 实时系统：强调及时响应，常分为硬实时和软实时。
- 微机操作系统：单用户单任务、单用户多任务、多用户多任务。
- 网络操作系统：支持网络资源共享，常见 C/S、P2P。
- 分布式操作系统、嵌入式操作系统：了解概念即可。

### 1.6 用户态与内核态

划分原因：保证系统安全性和可靠性，防止用户程序随意执行敏感操作。

- 用户态：只能执行非特权指令，不能直接访问关键系统资源。
- 内核态：可执行特权指令，能访问和管理系统资源。
- 典型切换原因：系统调用、中断、异常。

### 1.7 特权指令、非特权指令、PSW

- 特权指令：只能在内核态执行，如 I/O 指令、修改中断屏蔽字、设置系统状态等。
- 非特权指令：用户态也能执行的普通运算、访存等指令。
- PSW：Program Status Word，程序状态字，保存程序运行状态、条件码、中断状态、CPU 状态等信息。

### 1.8 中断与通道

多道程序实现需要硬件支持，老师强调两个基础：中断和通道。

- 中断：CPU 暂停当前程序，转去处理突发事件，处理完后恢复原程序。
- 通道：专门处理 I/O 设备的数据传输的处理器，但一般没有独立内存，需要使用主存。

中断处理三步：

1. 保护现场。
2. 处理中断。
3. 恢复现场。

## 第二章 CPU 管理 / 进程管理

### 2.1 程序顺序执行特征

- 顺序性：操作按规定顺序执行。
- 封闭性：程序运行时独占所需资源，不受外界影响。
- 可再现性：初始条件相同，结果相同。

### 2.2 并发执行特征

并发是多个程序在同一时间间隔内交替推进。

特点：

- 间断性。
- 失去封闭性。
- 不可再现性。

### 2.3 进程定义

进程是可并发执行、具有独立功能的程序关于某个数据集合的一次执行过程，也是操作系统进行资源分配和保护的基本单位。

进程实体 = 程序段 + 数据段 + PCB。

PCB：Process Control Block，进程控制块，是进程存在的唯一标志，保存进程标识、状态、调度信息、资源清单、现场信息等。

### 2.4 进程特征

- 动态性：进程有创建、运行、阻塞、终止等生命周期。
- 并发性：多个进程可并发执行。
- 独立性：进程是资源分配和调度的基本单位。
- 异步性：进程推进速度不可预知。
- 结构性：由程序段、数据段、PCB 构成。

### 2.5 进程状态转换

三态模型：

- 就绪态：具备运行条件，只缺 CPU。
- 运行态：正在 CPU 上执行。
- 阻塞态：等待某事件完成，如 I/O。

常见转换：

- 就绪 -> 运行：被调度。
- 运行 -> 就绪：时间片用完或被高优先级进程抢占。
- 运行 -> 阻塞：请求 I/O 或等待事件。
- 阻塞 -> 就绪：等待事件完成。

五态模型：创建态、就绪态、运行态、阻塞态、终止态。

带挂起模型：在就绪/阻塞基础上增加挂起，就绪挂起、阻塞挂起常与内存和外存交换结合考。

### 2.6 原语与原子性

原语是由若干条指令组成、用于完成特定系统功能的一段程序。执行时不可被中断。

原子性：要么不执行，要么一次执行完，执行中不能被打断。

### 2.7 作业

作业是用户提交给操作系统完成的一项任务。

作业通常包括：

- 程序。
- 数据。
- 作业说明书。

### 2.8 三级调度

- 高级调度/作业调度：从外存后备队列选择作业进入内存。
- 中级调度/内存调度：负责进程挂起与激活，实现内外存交换。
- 低级调度/进程调度：从就绪队列选择进程分配 CPU，最频繁。

### 2.9 调度方式

- 非抢占式：进程主动放弃 CPU 前不会被强行剥夺。
- 抢占式：可因时间片到、高优先级进程到达等原因抢占 CPU。

### 2.10 调度算法与计算

常考算法：

- FCFS：先来先服务。
- SJF/SPF：短作业/短进程优先。
- HRRN：高响应比优先，响应比 = (等待时间 + 服务时间) / 服务时间。
- 时间片轮转 RR：按时间片轮流运行。
- 优先级调度：按优先级选择。

计算公式：

- 完成时间 = 进程结束运行的时刻。
- 周转时间 = 完成时间 - 到达时间。
- 带权周转时间 = 周转时间 / 服务时间。
- 平均周转时间 = 各周转时间之和 / 作业数。
- 平均带权周转时间 = 各带权周转时间之和 / 作业数。

做题步骤：

1. 按算法画甘特图。
2. 写每个作业的完成时间。
3. 算周转时间、带权周转时间。
4. 求平均值。

### 2.11 线程

线程是进程内一个相对独立的执行流，是 CPU 调度的基本单位。

线程与进程区别：

- 进程是资源分配基本单位，线程是调度基本单位。
- 同一进程内线程共享进程资源。
- 线程切换开销通常小于进程切换。

## 第三章 进程同步、通信与死锁

### 3.1 同步与互斥

- 同步：多个进程因执行顺序约束而相互等待、协作。
- 互斥：多个进程不能同时访问同一临界资源。

临界资源：一次只允许一个进程访问的资源。

临界区：访问临界资源的代码段。

### 3.2 临界区访问原则

- 空闲让进：临界区空闲时，应允许请求进程进入。
- 忙则等待：已有进程进入时，其他请求进程等待。
- 有限等待：等待进程应在有限时间内进入。
- 让权等待：不能进入时应释放 CPU，避免忙等。

### 3.3 信号量与 PV 操作

信号量是表示资源数量或同步条件的整型变量，只能通过 P、V 原语访问。

- P(S)：申请资源，S = S - 1；若 S < 0，则阻塞。
- V(S)：释放资源，S = S + 1；若 S <= 0，则唤醒等待进程。

老师强调：信号量初值是关键。

### 3.4 PV 题通用模板

互斥模板：

```text
semaphore mutex = 1;

P(mutex);
访问临界资源;
V(mutex);
```

前驱关系模板：若 A 必须在 B 前执行：

```text
semaphore s = 0;

进程 A:
  A;
  V(s);

进程 B:
  P(s);
  B;
```

生产者-消费者模板：

```text
semaphore mutex = 1;
semaphore empty = n;
semaphore full = 0;

producer:
  while true:
    生产产品;
    P(empty);
    P(mutex);
    放入缓冲区;
    V(mutex);
    V(full);

consumer:
  while true:
    P(full);
    P(mutex);
    取出产品;
    V(mutex);
    V(empty);
    消费产品;
```

哲学家进餐：重点理解死锁风险。常见处理：

- 最多允许 4 个哲学家同时拿筷子。
- 奇偶哲学家拿筷子顺序相反。
- 同时申请左右两支筷子。

读者-写者：区分读读共享、写写互斥、读写互斥。

### 3.5 进程通信

考试不重点考复杂通信，了解即可。

- 共享存储。
- 消息传递。
- 管道通信。

### 3.6 死锁

死锁：多个进程因竞争资源而相互等待，若无外力作用都不能继续推进。

死锁产生四个必要条件：

1. 互斥条件：资源一次只能被一个进程占用。
2. 不剥夺条件：资源不能被强行抢占。
3. 请求并保持条件：进程已占有资源，又申请新资源。
4. 循环等待条件：存在进程资源循环等待链。

### 3.7 资源分类

- 可抢占资源：CPU、内存等。
- 不可抢占资源：打印机等。

### 3.8 死锁处理

- 预防死锁：破坏四个必要条件之一。
- 避免死锁：动态判断是否进入安全状态，典型是银行家算法。
- 检测死锁：用资源分配图或检测算法发现死锁。
- 解除死锁：剥夺资源、撤销进程、回退等。

### 3.9 安全状态与银行家算法

安全状态：系统存在一个安全序列，使所有进程都能顺利完成。

银行家算法基本数据：

- Available：系统可用资源。
- Max：进程最大需求。
- Allocation：已分配资源。
- Need = Max - Allocation：尚需资源。

判断步骤：

1. 检查 Request <= Need。
2. 检查 Request <= Available。
3. 试分配。
4. 用安全性算法找安全序列。
5. 若能找到安全序列，则允许分配；否则拒绝。

老师提示：银行家算法是难点但不算最重点，理解课本例题即可。

### 3.10 资源分配图

- 圆圈：进程。
- 方框：资源类；方框内小点表示资源实例。
- 请求边：进程 -> 资源。
- 分配边：资源实例 -> 进程。

## 第四章 存储管理

### 4.1 逻辑地址与物理地址

- 逻辑地址：程序中使用的地址，又称相对地址、虚地址。
- 物理地址：内存中的实际地址，又称绝对地址、实地址。

### 4.2 重定位

- 静态重定位：程序装入内存时一次性完成地址变换，运行中不能移动。
- 动态重定位：程序运行时由硬件地址变换机构完成，运行中可移动。

### 4.3 连续分配管理

单一连续分配：内存分为系统区和用户区，一次只装入一道用户程序。

固定分区分配：

- 分区大小固定。
- 简单，但容易产生内部碎片。

可变分区分配：

- 按作业大小动态划分分区。
- 容易产生外部碎片，可用紧凑技术处理。

常见可变分区算法：

- 首次适应 FF：按地址从低到高找第一个满足的空闲区。
- 循环首次适应 NF：从上次查找位置继续找。
- 最佳适应 BF：选能满足且最小的空闲区。
- 最坏适应 WF：选最大的空闲区。

注意：最佳/最坏不是绝对好坏，只是选择策略不同。

### 4.4 覆盖与交换

- 覆盖：把程序划分为若干段，必要时调入覆盖区，解决小内存运行大程序。
- 交换：把暂时不用的进程从内存换出到外存，需要时再换入。

### 4.5 分页存储管理

核心：把逻辑地址空间分成等长页，把物理内存分成等长块/页框，页大小 = 块大小。

优点：

- 无外部碎片。
- 内存利用率较高。
- 便于虚拟存储。

缺点：

- 可能有页内碎片。
- 需要页表，占用内存。

地址结构：

```text
逻辑地址 = 页号 P + 页内偏移 W
物理地址 = 块号 F + 页内偏移 W
```

若页面大小为 `2^k`，则低 k 位是页内偏移，其余高位是页号。

分页地址转换步骤：

1. 根据页面大小拆分页号 P 和页内偏移 W。
2. 查页表，判断页号是否存在/是否越界。
3. 取出物理块号 F。
4. 拼接物理地址：`F * 页面大小 + W`，或二进制拼接 `F + W`。

### 4.6 快表 TLB

快表也叫联想存储器，用于缓存页表项，提高地址转换速度。

- 命中：直接得到块号。
- 未命中：访问内存中的页表，再更新快表。

### 4.7 多级页表与倒置页表

多级页表目的：

- 减少页表连续占用内存的压力。
- 扩大虚拟地址空间管理能力。

查找方式：先查一级页表，再查二级页表，直到得到页框号。

倒置页表：按物理块建立页表项，逻辑上是“反过来”的页表。

### 4.8 分段存储管理

分段按程序逻辑结构划分，如主程序段、子程序段、数据段、栈段等。

地址结构：

```text
逻辑地址 = 段号 S + 段内地址 W
```

段表项通常包括：

- 段基址。
- 段长。

分段地址转换步骤：

1. 判断段号是否越界。
2. 查段表得到段基址和段长。
3. 判断段内地址是否小于段长。
4. 物理地址 = 段基址 + 段内地址。

分页与分段区别：

- 页是信息的物理单位，段是信息的逻辑单位。
- 页大小固定，段长度不固定。
- 分页地址空间一维，分段地址空间二维。
- 分页主要为系统管理内存，分段更符合用户程序逻辑。

### 4.9 段页式存储管理

先分段，段内再分页。

地址结构：

```text
逻辑地址 = 段号 S + 段内页号 P + 页内偏移 W
```

查表步骤：

1. 用段号查段表，得到该段页表起始地址和页表长度。
2. 判断段内页号是否越界。
3. 查页表得到物理块号。
4. 物理地址 = 块号 * 页大小 + 页内偏移。

### 4.10 虚拟存储管理

虚拟存储：把内存和外存结合起来，使用户感觉有比实际内存更大的存储空间。

基础：

- 局部性原理。
- 请求调页/请求分段。
- 页面置换。

局部性原理：

- 时间局部性：刚访问过的内容近期可能再次访问。
- 空间局部性：刚访问位置附近的内容近期可能被访问。

### 4.11 页面置换算法

常考计算：

- 缺页次数。
- 缺页率 = 缺页次数 / 访问页面总次数。

算法：

- FIFO：淘汰最早进入内存的页面。
- OPT：淘汰未来最长时间不会访问的页面，理论最优，实际不可实现。
- LRU：淘汰最近最长时间未使用的页面，用过去推测未来。
- CLOCK：近似 LRU，了解即可。

做题步骤：

1. 画页框表。
2. 按访问串逐个填。
3. 标出缺页位置。
4. 数缺页次数，算缺页率。

老师强调：分页、段表、页表、LRU 是存储管理大题重点，二进制位数不要拆错。

## 第五章 设备管理

### 5.1 I/O 设备分类

按信息传输单位：

- 字符设备：以字符为单位，如键盘、打印机。
- 块设备：以数据块为单位，如磁盘。

按资源分配方式：

- 独占设备。
- 共享设备。
- 虚拟设备。

### 5.2 I/O 控制方式

- 程序直接控制方式：CPU 不断查询设备状态，效率低。
- 中断控制方式：设备完成后发中断，CPU 利用率提高。
- DMA 方式：直接在内存和设备间传输数据，CPU 只参与初始化和结束处理。
- 通道方式：由通道专门管理 I/O 操作，进一步减轻 CPU 负担。

### 5.3 缓冲技术

缓冲目的：

- 缓和 CPU 与 I/O 设备速度不匹配。
- 减少中断次数。
- 提高并行性。

高速缓存 Cache 与缓冲区区别：

- Cache 主要缓解 CPU 与主存速度差，存放主存副本。
- 缓冲区主要缓解设备与 CPU/内存速度差，存放 I/O 数据。

### 5.4 虚拟设备与 SPOOLing

SPOOLing：假脱机技术，把独占设备改造成逻辑上的共享设备。

典型例子：打印机假脱机。

组成：

- 输入井、输出井。
- 输入进程、输出进程。
- 输入缓冲区、输出缓冲区。

### 5.5 设备分配数据结构

需要记住四张表：

- SDT：系统设备表。
- DCT：设备控制表。
- COCT：控制器控制表。
- CHCT：通道控制表。

### 5.6 磁盘结构

磁盘地址常由柱面号、磁头号、扇区号组成。

访问时间：

```text
磁盘访问时间 = 寻道时间 + 旋转延迟时间 + 传输时间
```

### 5.7 磁盘调度算法

常考算法：

- FCFS：按请求到达顺序服务。
- SSTF：最短寻道时间优先，优先服务离当前磁头最近的请求。
- SCAN：电梯算法，磁头按一个方向移动，途中服务请求，到端点后反向。
- C-SCAN：单向扫描，到端点后快速回到另一端继续同向扫描。

做题步骤：

1. 标出初始磁头位置和移动方向。
2. 按算法写访问顺序。
3. 逐段计算磁道移动距离。
4. 求总移动道数。

老师提示：磁盘调度题好出，数字一换即可，千万别把算法顺序搞错。

## 第六章 文件管理

### 6.1 文件与文件系统

文件：具有符号名的一组相关信息集合。

文件系统：操作系统中负责文件存取、组织、保护和管理的软件集合。

### 6.2 文件分类

常见分类：

- 普通文件。
- 目录文件。
- 特殊文件/设备文件。

也可按逻辑结构分：

- 流式文件。
- 记录式文件。

### 6.3 虚拟文件系统 VFS

VFS 能连接不同文件系统的原因：它定义了各种文件系统都支持的统一接口和数据结构。

注意：VFS 严格意义上不是磁盘上固定存在的文件系统，主要存在于内存中，使用时建立相关结构。

### 6.4 文件逻辑结构与物理结构

逻辑结构：从用户角度看到的文件组织。

物理结构：文件在外存上的存放方式。

常见物理结构：

- 连续结构：访问快，但容易产生外部碎片，不利于文件增长。
- 链接结构：便于增长，无外部碎片，但随机访问差。
- 索引结构：通过索引表记录块地址，支持随机访问，索引表占空间。

### 6.5 FAT、FCB、目录

- FCB：File Control Block，文件控制块，保存文件名、物理位置、属性等，是文件存在的重要标志。
- FAT：File Allocation Table，文件分配表，用于记录文件各磁盘块的链接关系。
- 目录：由若干目录项组成，用于文件检索。

文件目录作用：

- 实现按名存取。
- 提高文件检索速度。
- 允许文件共享。
- 支持文件重名控制。

### 6.6 目录结构

- 单级目录：简单，但不允许重名，检索效率低。
- 二级目录：主文件目录 + 用户文件目录。
- 多级目录/树形目录：层次清晰，支持重名，现代系统常用。

### 6.7 文件存储空间管理

常见方法：

- 空闲表法。
- 空闲链表法。
- 位示图法。
- 成组链接法。

位示图计算：

- 每一位表示一个磁盘块是否空闲。
- 若题目问第几行第几列，注意是否从 0 开始；老师提示可按题目给的行列直接 `a + b` 思路处理，关键是别漏单位和起始编号说明。

### 6.8 索引结构计算

重点看课本例题 6.1。

做题思路：

1. 明确每个磁盘块大小。
2. 明确每个索引项大小。
3. 算一个索引块能存多少索引项。
4. 分别计算直接索引、一级间接索引、二级间接索引可寻址的文件大小。

## 高频名词解释速记

- 操作系统：管理软硬件资源、控制程序执行、提供接口的系统软件。
- 进程：程序在某数据集合上的一次执行过程，是资源分配和保护基本单位。
- PCB：进程控制块，保存进程状态和控制信息，是进程存在的唯一标志。
- 线程：进程内的执行流，是 CPU 调度基本单位。
- 原语：不可中断执行的系统程序段，具有原子性。
- 临界资源：一次只允许一个进程访问的资源。
- 临界区：访问临界资源的代码段。
- 信号量：用于同步和互斥的整型变量，只能由 P/V 原语操作。
- 死锁：多个进程相互等待对方资源而都不能推进。
- 安全状态：存在一个安全序列，使所有进程均可完成。
- 逻辑地址：程序使用的地址。
- 物理地址：内存中的实际地址。
- 重定位：把逻辑地址转换为物理地址。
- 页表：记录页号到物理块号映射的数据结构。
- 段表：记录段基址和段长的数据结构。
- 虚拟存储：内外存结合形成比实际内存更大的逻辑存储空间。
- 缺页中断：访问页面不在内存时产生的中断。
- SPOOLing：假脱机技术，将独占设备虚拟成共享设备。
- FCB：文件控制块。
- FAT：文件分配表。
- VFS：虚拟文件系统，提供统一文件系统接口和数据结构。

### B. 分页地址转换模板

```text
页面大小 = 2^k
逻辑地址 A:
  页号 P = A / 页面大小
  页内偏移 W = A % 页面大小
查页表:
  若 P 越界或无效 -> 越界/缺页
  否则块号 F = 页表[P]
物理地址 = F * 页面大小 + W
```

### C. 分段地址转换模板

```text
逻辑地址 = (段号 S, 段内地址 W)
查段表:
  若 S 越界 -> 越界
  若 W >= 段长 -> 越界
  否则物理地址 = 段基址 + W
```
