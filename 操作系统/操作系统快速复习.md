## 3. 第二章必背

### 顺序执行三个特点

- 顺序性
- 封闭性
- 可再现性

### 进程

定义：

- 程序关于某个数据集合的一次执行过程
- 资源分配和保护的基本单位

进程实体：

`程序段 + 数据段 + PCB`

### 进程特征

- 动态性
- 并发性
- 独立性
- 异步性
- 结构性

### 进程三态

- 就绪
- 运行
- 阻塞

### 三级调度

- 高级调度：作业进入内存
- 中级调度：挂起与激活
- 低级调度：选进程占用 CPU

### 原语和原子性

- 原语：不可中断操作
- 原子性：要么不做，要做就一次做完

### 调度题公式

- 周转时间 = 完成时间 - 到达时间
- 带权周转时间 = 周转时间 / 服务时间

### 高频调度算法

- FCFS
- SJF
- HRRN
- RR

HRRN：

`响应比 = (等待时间 + 服务时间) / 服务时间`

## 4. 第三章必背

### 同步与互斥

- 同步：有先后顺序约束
- 互斥：不能同时访问同一临界资源

### 临界区原则

- 空闲让进
- 忙则等待
- 有限等待
- 让权等待

### P/V 操作

- P：申请资源
- V：释放资源

关键信息：

- 信号量初值最重要

### 互斥模板

```text
semaphore mutex = 1;
P(mutex);
临界区;
V(mutex);
```

### 前驱模板

```text
semaphore s = 0;

A执行完: V(s)
B执行前: P(s)
```

### 死锁四个必要条件

1. 互斥
2. 不剥夺
3. 请求并保持
4. 循环等待

### 安全状态

- 存在安全序列，所有进程都能完成

## 5. 第四章必背

### 逻辑地址和物理地址

- 逻辑地址：程序用的地址
- 物理地址：内存中的实际地址

### 连续分配算法

- FF
- NF
- BF
- WF

### 分页

逻辑地址：

`页号P + 页内位移W`

物理地址：

`块号F + 页内位移W`

公式：

`物理地址 = F × 页面大小 + W`

### 分段

逻辑地址：

`段号S + 段内位移W`

公式：

`物理地址 = 段基址 + 段内位移`

### 分页和分段区别

- 页固定，段不固定
- 页偏物理，段偏逻辑

### 段页式

- 先分段，再分页

### 局部性原理

- 时间局部性
- 空间局部性

### 页面置换

- FIFO
- OPT
- LRU

记忆：

- OPT 最优但做不到
- LRU 用过去推测未来

缺页率：

`缺页率 = 缺页次数 / 访问总次数`
